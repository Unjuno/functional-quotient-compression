# MA-351 — MIMO + Mirror view diversity

Status: SCREENING. Prior art: PA42 MIMO implicit ensembles.

## H

For eight synthetic member tasks whose logistic heads vary by a shared planar rotation, a shared head plus learned Mirror phase per member may preserve member quality/disagreement at lower bytes than an ordinary multi-input/multi-output bank of independent heads while evaluating all members in one batched call. A generic shared low-rank coefficient control may match it.

## Mirror insertion

> **Mirror insertion:** this experiment adds a per-member angle `m` to a shared 8D linear classifier, rotating its first two coordinates to recover member-specific decision functions without storing eight full heads.

Compare shared single head, MIMO-style independent heads trained/evaluated jointly, shared Mirror head+angles, and shared generic rank-2 coefficient basis. Use one batch call across all members, same examples and update count. Report mean member NLL/ECE/accuracy, member disagreement/correlation, actual bytes and batched throughput.

## T

Eight member tasks, 8D Gaussian inputs and binary logistic labels. Teacher heads are generated by rotating the first two coordinates of one shared weight vector. Development worlds 35121–35122; fresh 35131–35133; 256 train and 1,024 test examples/member. Train all methods jointly for 1,000 Adam updates. No task labels or test data are shared across train/test examples.

## Gates

**PROMISING:** Mirror mean NLL within .02 and disagreement within .02 of MIMO, with <=.80x MIMO payload and <=.90x generic basis payload; retain one-batched-call inference. **FAIL:** quality/diversity falls or generic code matches within 10% bytes and quality. This is fixed-budget learning efficiency, not capacity.

## C / U

Teacher heads are planted on the same rotation orbit as Mirror. The MIMO control is a linear multi-input/multi-output analogue, not a reproduced deep MIMO implementation. Natural ensemble diversity and calibrated uncertainty are untested.

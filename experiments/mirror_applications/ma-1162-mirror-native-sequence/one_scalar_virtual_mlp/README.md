# MA-1162 exploratory: exactly-one-scalar virtual Mirror-generated MLP

**Research branch only — not a completed general Mirror-compression result.**

> **Mirror insertion:** One and only one learned scalar `s` is lifted analytically into an intermediate coordinate vector and repeatedly transformed as `Q^-1 tanh(Q z + bias)` (with residual mixing). The resulting virtual coefficient vector is parsed into the six weight/bias tensors of an ordinary 2→16→16→1 MLP. No individual weight is learned or stored. The intended saving is replacement of independently stored MLP weights by one scalar plus a deterministic decoding program.

## Research question

Can a single differentiable scalar, transformed by multiple interleaved Mirror and nonlinear operators, generate an **executable multi-layer MLP** and be learned by gradient descent? Under what task restrictions is this useful? Does it generalize to a non-Mirror teacher?

The answer is **YES** to construction/backprop/aligned-teacher fitting, **NO** to strong out-of-family function approximation for this frozen experiment. 337 virtual MLP coefficients do not imply 337 independent learnable degrees of freedom.

## Files

- `source/model.py`: scalar-based differentiable Mirror virtual-weight synthesis, ordinary MLP execution, stronger dense control.
- `source/run.py`: synthetic task generation and development/fresh harness.
- `source/diagnose_dev_tangent.py`: post-hoc development-only local-tangent gradient alignment.
- `tests/test_model.py`: architecture, gradient numerical finite difference, reversible Mirror, exact serialization, exact parameter count.
- `PROTOCOL_FROZEN.json`: hyperparameters and evaluation gates frozen before fresh examples.
- `results/fresh_500_lr003.csv`: all 60 fresh rows, including negative controls.
- `VERIFICATION.json`: checksum, gate and accounting audit.
- `REPORT_JA.md`: Japanese interpretation, restrictions and future work.

Run from this experiment directory:

```bash
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -m pytest -q tests
OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 python -m source.run --phase fresh --lr 0.03 --updates 500 --out results/fresh_500_lr003.csv
```

The second command refuses to overwrite an existing CSV; use a new output path for a clean reproduction.

## Caveats

- **One trainable scalar** refers to one binary64 scalar; source code, nonlearned analytic constants and framework are still required and cannot be counted as free deployment state.
- Fixed-depth generator uses 4 rotations/permutation/nonlinear steps. Mirror codes are computed from `s` and round indices; no separate learnable generator network.
- Aligned teachers are generated by the *same* scalar-Mirror program; success here is only a feasibility result, not independently acquired RNN/Transformer capability.
- Out-of-family function fails at the tested budget while an ordinary 337-parameter MLP succeeds.
- High-precision p=46, 8000, 80000 bit **optimization was not executed** here; binary64 is a distinct regime.

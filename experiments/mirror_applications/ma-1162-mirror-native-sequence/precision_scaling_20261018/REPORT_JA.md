# 1物理スカラーの精度スケーリング — Mirror+非線形仮想重み 検証 (2026-10-18)

## 1. 核心

「物理学習パラメータ数を固定して、数値の精度 p ビットを増やす」ことで、保存可能な状態数と*同一Mirror規則の軌道上*での分解能は増える。しかし、微分可能な1スカラーから生成された仮想重みの**局所的な独立調整方向は最大1**。この区別を固定アルゴリズムで実測した。

この実験は **8本の仮想Mirror重みを生成する機構スクリーニング**であり、RNNのend-to-end学習やGPU検証ではない。FP8000はPyTorchにないので、pビット固定小数点を任意精度演算 `mpmath` で扱った。これはIEEE浮動小数点の符号・指数・仮数すべてを含む「総ビット長 p」とは異なる。

### 数理構造

- 同一スカラー s から8種類の役割を生成。各役割で **可逆Mirror → tanh → 逆Mirror** を2回行い残差混合。
- 生成器は学習可能なベクトルや役割別スカラーを一切保持しない。
- 各更新の構造は `z_next = 0.73*z + 0.27*Q^-1*tanh(1.15*Q*z+b)`。
- **次元チェック:** z,b は2×1、Qは2×2であり、加算、掛け算、逆変換は全て合法。全変数は無次元。時間はmsとして測り、1ms = 10^-3 s。

**局所ランクの証明:** w(s)=(w_1(s),…,w_8(s)) の各要素は微分可能な1変数関数。したがってヤコビアンの列数は1、rank(J)≤1（列がゼロなら0）。途中に活性化関数や多段Mirrorを任意に追加しても、微分可能である限りこのランク制約は変わらない。ただし、生成可能な**離散状態の個数**は最大2^pであり、pに従って増加し得る。

**精度と条件数の両立問題:** `|w(s+2^-p)-w(s)| ≤ L * 2^-p`。最下位1ビット変化に対して出力を一定値 c>0 以上変えたければ `L ≥ c*2^p` が必要。強いビット感度は、微小摂動や勾配の不安定性とトレードオフする。

## 3. H/T/D/C/U

**H（反証可能仮説）**：同型教師（固定プログラムの生成軌道上）では p 増加が量子化による適合誤差を下げるが、同プログラム外の教師では有限の残差を消せない。一方、固定の高周波Mirrorアドレス `2^j` は p>j のとき最下位ビット情報へ応答し得る。

**T（最小検証）**：固定教師 s*（8192ビット決定的生成）、8仮想役割、1スカラーGauss-Newton（解析微分、丸め、最大24更新）。同型教師と真の接ベクトルに直交する0.2ノルムの変更を加えた*off-orbit*教師。上述8精度を評価。周波数 `2^j` は固定リスト `{0,3,16,48,96,192,384,768,7000}` で比較。CPU AMD EPYC 9V74、5 vCPUコンテナ、PyTorchなしのCPU mpmath。n=1決定論的世界・各条件1学習、統計的な一般化は主張しない。

**D（観測と合否）**：スカラーpを上げると同型教師誤差は強く低下する一方、off-orbitはMSE約0.005のまま。ビット感度のあるMirror位相は追加可能だが、高周波化が不可欠。`GLOBAL MODEL CAPACITY / GPU SPEED = UNTESTED`。

**C（対立仮説）**：同型教師の成功は教師を事前に同じ生成軌道に置いたことによる。高周波プログラムなら同一スカラーの低位ビットから多くの状態を引き出せるが、極端な損失の振動、多数の極小値、勾配の条件悪化を招き得る。アドレスごとの独立更新は通常の1次元勾配学習と別の最適化機構である。

**U（不確実性）**：単一決定論的教師、合成モデル8スカラー、丸め誤差とMP実装、Pythonオーバーヘッド、生成プログラムの未課金コードサイズ、GPU未測定。pビットに対して演算時最低p+40ビット、学習・教師適合評価はp+160ビット（教師の初期生成8192+200ビット）。u_c及びkの統計的区間はn=1のため定義・推定できない。

### 位相増幅の診断

固定プログラム `sin(2π * 2^j s)` を活性化つきのMirrorで評価すると、p≤jでは整数位相となり**そのビューがスカラーに依存せず**、p>jで低位の情報が出現する。ただしその最下位ビット応答は p-j が大きいと小さい。例：p=8000かつj=7000ではスカラー最下位1ビットを変更した仮想出力差は約1.07e-301（高精度では非ゼロだが普通のFP64計算では役立たない）。

**追加の事後診断（主要事前固定ゲートに含めない）**：各pでj=p-2を選べば同じ1ULP変化が0.07〜0.24の有限の出力差になる。大きなビット精度は実際に仮想機能の細かい変化に使えるが、その生成器の位相感度も指数的に高くなる。これは独立学習自由度の増加を意味しない。

## 5. VRAM/オフロードへの含意

- p=80,000なら**理論上の生データは10,000 B = 9.77 KiB**。CPU実験で測定したのはp=8,000まで、80,000の実行速度は未知。
- スカラー1個なら大きなモデルの**物理重みオフロードは原理上不要**。GPUへそのビット列を一度置けばよい。ただしGPUに任意精度のTensor Core演算があるわけではない。整数 limb 表現やカスタムCUDAによる高精度演算が必要。
- 仮想重みを全て展開すれば通常の `Nvirt * dtype_bytes` メモリが再発する。**行列を展開せず作用として適用する fused / matrix-free generator** が成立すれば削減できる。
- RNN推論中の隠れ状態、学習中のBPTT保存活性、中間Mirrorワークスペースは、スカラーが小さくても別にメモリを消費する。
- 同一状態からK個のMirrorを並列に適用できるが、Kに応じた演算とscratchは必要。1個のsへの勾配は合計されるため独立にK方向へ学習するわけではない。
- 例：4096×4096の通常再帰重み1枚のFP16保存だけで32MiB。その重みを生成して逐次適用できれば常駐重み32MiBは減らせるが、`4096²`の密行列積コストも同時に消えるとは限らない。
- 情報理論上の比較：80,000ビットはFP16重み5,000個の生ストレージに相当する。仮想重みがそれより少ないなら同条件での「圧縮」ではなくむしろ増量となる。

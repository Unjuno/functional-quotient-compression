## Hypothesis

H: For few-shot linear task functions on a two-angle coefficient orbit, a meta-trained shared predictor adapted only through two Mirror angles will approach full first-order MAML quality, require less serialized task-bank storage, and outperform a byte-near rank-2 LoRA adaptation. A native Givens-angle conditioner that matches Mirror invalidates Mirror-specific attribution.

**Mirror insertion:** this experiment adds two support-adapted angles `m` to a shared linear predictor so held-out task functions can be specialized without storing a six-weight vector for every task.

## Scope and task

A 6D linear regressor is meta-trained over disjoint synthetic task identities. Each task coefficient vector is generated by two Givens rotations of a shared template. Four inner updates use eight support examples; evaluation uses 32 query examples. Methods are shared/no-adapt, first-order MAML updating six weights, Mirror-only two-angle adaptation, learned rank-2 additive LoRA, a native Givens-angle control, and independent task vectors. Two seeds (44201, 44202) are development worlds. Fresh seeds 44211–44213 stay unopened unless every development gate passes.

This is a mechanism screen, not evidence about neural backbones or natural tasks. FOMAML is first-order; the study measures query RMSE, actual serialized inference payload, optimizer/example counts, and CPU wall time.

## Controls and gate

Full MAML is the quality/storage upper control; shared/no-adapt is the lower control; rank-2 LoRA is the low-rank adaptation baseline; native Givens conditioning tests whether the chosen `m` is an ordinary native parameter. A 16-task inference bank is serialized as an uncompressed `.npz` containing all arrays and schema metadata. The complete frozen gates are in `PROTOCOL.json`.

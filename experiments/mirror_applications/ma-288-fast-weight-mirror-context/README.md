# MA-288 — Mirror fast-weight programmer context code

## H — Hypothesis

A dynamic context-to-code map can select useful fast-weight memory functions with less state than storing explicit per-session updates, while generalizing to held-out context combinations.

## T — Planned experiment

Synthetic context-conditioned rank-2 linear rule; compare outer-product fast weights, explicit per-context updates, static IDs, dynamic Mirror code, generic linear rank-2 code and generic MLP generator. Hold out complete context identities. Development added the generic rank-2 control before fresh because it shares the Mirror code's function class. Fresh worlds 28810–28812 × seeds 0–2 remain locked.

## C — Strongest counter-hypothesis

## H — hypothesis

A permutation address can align symmetry-equivalent hidden units, after which a one-phase Mirror code may represent six task deltas on a shared two-direction orbit more compactly than direct task-vector coefficients. Two unrelated tasks measure the need for private state.

## Mirror insertion

> **Mirror insertion:** apply a charged hidden-unit permutation address to map each logical task into a shared base coordinate system, then add its delta using a shared basis and small task code.

- Native method: independent task vectors and Re-Basin permutation alignment.
- Exact Mirror location: task-delta coordinate over the aligned basis.
- Nearest control: same alignment and shared basis with direct two-coefficient task codes.
- Symmetry audit: permutation alone must preserve the MLP output exactly; it is not counted as new function multiplicity.

## Prior art

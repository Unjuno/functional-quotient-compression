# MA-871 results: reusable module composition structure

## H — Hypothesis

A low-dimensional recombination structure learned from prior tasks should let a new task recover useful behavior from fewer examples and with fewer inference bytes than storing independent coefficients over the same reusable module bank. A Mirror-specific result also must beat a native PCA/bilinear factorization at comparable bytes and compute.

## T — Trial

The frozen PA234-inspired mechanism screen uses eight fixed nonlinear module functions `tanh(w_j dot x + b_j)`. Each task is generated by a two-dimensional latent code times an 8D recombination basis. Twelve training tasks estimate that basis; six heldout tasks use independent latent codes. Fresh worlds were seeds 907, 919, and 937, with 4,096 heldout examples per task and support sweeps of 4, 8, 16, and 32. Controls: direct eight-coefficient support fit, nearest training-task coefficient codebook, random rank-2 basis, native rank-2 PCA, pooled coefficients, and teacher coefficients. Development seed 809 was separate.

The preregistered pre-fresh amendment set the six-task storage gate to 10% after exact payload arithmetic showed 16.4% as the maximum expected saving for the chosen object sizes. The protocol and amendment were fixed before fresh seeds were run.

## D — Decision

**FAIL for Mirror-specific attribution; synthetic native structure screen passes its narrow quality, support, and storage gates.** At 8 examples, every fresh world met the MSE gate; shared rank-2 payload is 408 B versus 488 B for independent coefficients (16.4% lower). Native PCA has the same outputs, bytes, and decoder operation count, so the gain belongs to native low-rank structural composition rather than Mirror.

## C — Strongest counter-hypothesis

The two-dimensional task geometry is recovered by ordinary PCA over training-task coefficients and adapted by a standard linear least-squares code. No additional Mirror parameterization is needed. The experiment intentionally generated tasks from exactly this rank-2 structure.

## U — Unconfirmed

Natural task compositions, learned neural modules, RL/sample-reward adaptation, noisy or changing module banks, larger task counts, rank selection, and unseen recombination mechanisms remain untested. This is not a reproduction of the original PA234 benchmark.

## Facts

- At 8 support examples, fresh per-world mean function MSE was 0.000801, 0.000302, and 0.000224; worst heldout task across all 18 task-world pairs was 0.002357. The frozen threshold was 0.0025.
- At 4 examples, mean MSE across fresh worlds was 0.002025 and worst per-world mean was 0.003524; the all-world gate therefore first passes at 8 examples.
- At 8 examples, direct independent coefficient fitting had mean MSE 0.05578; the nearest training-task codebook 0.07516; random rank-2 basis 0.33674; pooled model 0.43621. Teacher coefficients had zero function error by construction.
- Six heldout task payloads including shared module bank and metadata cost 408 B for Mirror/rank-2 PCA, 488 B independent coefficients, 686 B codebook, and 328 B pooled coefficients. Rank-2 saves 16.4% versus independent.
- Mirror and native PCA outputs are exactly equal for all recorded fresh seeds/support sizes; their payload sizes and decode MAC proxies are equal.
- The shared module evaluation proxy is 72 MACs/query. Rank-2 decode is 48 MACs/query versus 16 for direct coefficient decode, so total proxy grows 36% (120 vs 88) while payload shrinks.
- Mean host adaptation time at 8 shots was about 0.100 ms for rank-2 versus 0.164 ms independent; mean measured heldout matmul time was about 0.051 ms versus 0.051 ms. Maximum full local screen wall time was 0.0251 s. These small host timings are not hardware-runtime claims.

## Interpretation

A training-task structural basis can make support inference data-efficient and reduce the charged task-bank payload in this synthetic family. Its storage benefit spends extra inference arithmetic for coordinate decode. The same benefit is obtained by standard rank-2 PCA, so the Mirror-specific hypothesis is falsified for this interface. Because the task generator is exactly rank 2, these observations do not establish capacity growth for arbitrary tasks.

## Hypothesis for follow-up

A new experiment could hold out module/rule combinations while independently varying the module bank and recombination mechanism. It should compare a learned structural coordinate against explicit module-selection codes and native tensor factorization, charging any basis discovery, codebook, or task-specific residual state.

# MA-1164B FP64-only 再解析：物理次元と保存精度を混同しない比較

**区分：事後再解析。新規fresh検証・再学習ではない。** FP16/FP32行を主比較から完全除外。元データはMA-1164Bの凍結済み3分割×2 seedの試験結果（同じscikit-learn数字画像集合を再分割した世界618460-618462）。

## 修正した比較の前提

- すべて **FP64の演算、学習係数、保存** に揃える。FP16・FP32量子化は独立の後段評価であり、この解析の主要因子から除外。
- Mirror・同物理次元plainは、物理mと仮想NN構造64→16(tanh)→10を一致させる。教師の学習済みFP64重みから直接コンパイルし、ラベル・logitsによる蒸留はしない。
- `plain`対照は反復非線形も除外するため、**Mirror回転だけの効果には分解できない**。幾何変換だけを替えて活性化・反復を一致させた対照が次に必要。
- 通常NNの幅縮小・低ランクはFP64ではあるが、「学習済みNNの後変換」ではなく「最初から学習」であることと、パラメータ数が厳密一致でないことを明示。

Mirrorの有効な学習パラメータはm個だが、1210重みの教師を先に900更新してから機械変換している。上の通常MLPは別途900更新で最初から直接学習。**学習方式・総学習計算量まで一致した比較ではない**。

## 次に必要な一因子実験

1. FP64固定・m固定・同じNN論理構造64→16→10固定。
2. K・反復回数R・tanh・残差係数を双方で一致させ、Qのみを`I`（回転なし）と`Q_m`（Mirror回転）に変更。比較する活性化への入力スケールも校正。
3. 「同じ教師重みへの機械コンパイル」と「教師を使わずラベルから直接学習」の二レーンを分離。双方で初期条件、試行数、更新数、評価データを固定。
4. まずK/R/物理mの発展をFP64で確定し、その後にFP32/FP64/任意精度固定小数点の精度軸だけを変える。物理次元と精度の二因子を混ぜない。

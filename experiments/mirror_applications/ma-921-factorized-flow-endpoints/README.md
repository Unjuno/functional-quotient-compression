# MA-921 — factorized flow-map endpoint views

Status: SCREENING

A frozen amendment 01 tests learned start/end endpoint codes on held-out time-pair combinations in three analytic 2D linear ODE worlds. It compares native continuous `(s,t)`, additive endpoint Mirror codes, and the ordinary learned additive endpoint-embedding control. The latter is structurally identical to the Mirror construction and is included to test attribution. The exact ODE map is the target oracle.

This is a mechanism screen only: it does not reproduce PA260 image experiments or claim FID/visual quality. See `PROTOCOL.json` for the frozen split and training budget.

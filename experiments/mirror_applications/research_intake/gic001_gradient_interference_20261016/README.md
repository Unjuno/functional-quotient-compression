# GIC-001 — 勾配衝突・表現限界・専用化先の実験

**2026-10-16 実行・監査完了。H2（PCGradによる救済）とH4（衝突スコア固有の選択優位）はFAIL。H3（追加private容量の効果）は限定PASS。main・MA台帳は変更しない。**

## 結論

今回の小模型では、**共有モデルが表現できない関数差へ自由度を割り当てることは有効だったが、勾配衝突の大きさだけでは適切な専用化先を選べなかった。** 過去のAMA/MN/MAの失敗すべてを勾配干渉へ帰属する結果ではない。

これは新規の機構切り分け実験であり、過去チェックポイントの再学習、Transformer、隠れ層に組み込んだKAN/GS-KAN、自然データの比較ではない。

## 対象・固定条件

**Mirror insertion:** 一つの親スプラインと共有変形方向へ2次元のタスク座標を追加して8関数を表し、選択した2タスクだけへ専用スプラインを追加する。

1入力・8タスク・固定ノット三次スプライン12基底。4条件は完全共通、rank2関連、2/8タスクに共有族外の例外を加える部分共有、無関係。既知タスクIDを使用する。rank2の式は普通の共有低ランクスプライン辞書と同一で、Mirror固有の発明とは主張しない。

開発44モデル、freshは5独立世界×3初期値×4条件×11方式=660モデル。主実験合計704モデル・1,056,000更新。各タスク256訓練入力、128検証入力、512テスト入力、訓練ラベルノイズ標準偏差0.03。全バッチAdam1500更新、学習率0.03と事前固定の減衰。ソース・プロトコルを開発前にハッシュ固定し、fresh後の調整なし。

十分統計を使う小さな係数モデルなので、更新数をTransformerの計算量と比較しない。以前の監査メモを具体化した新プロトコルであり、既存MAの採用試験ではない。否定結果も主目的のためfresh移行条件は実装・再現性であり、開発性能の成功ではない。

## 主結果：一部だけ共有できない場合

MSEはノイズを除いた真の関数について、入力[-1,1]一様分布で積分した無次元の誤差。各世界で3初期値の中央値を取り、次に5世界の中央値を取る。

### 何が明確になったか

部分共有条件の通常rank2は、全15設定で既知の訓練大域最小値との差が最大1.79e-12まで収束した。それでも正の誤差が残る。したがって、このケースを「勾配が衝突して最適化が進まない」と説明するのは不適切である。母集団の表現下限の世界中央値は0.225868。訓練最適解と母集団最適解の差は有限標本による推定誤差と区別する。

関連曲線条件では、通常rank2はPCGradなしで平均MSE 0.0000262。終盤の負の勾配余弦ペア率は世界中央値75%だった。高い衝突率だけでは学習失敗を判定できない。訓練ラベルのノイズも含む結果である。

真の2例外を両方選べた設定数は、衝突1/15、誤差4/15、ランダム1/15、全探索参照15/15。15は5世界内の3初期値反復であり、独立データセット15個ではない。大きな衝突を受けるタスクと、共有から外すと最も全体損失を下げるタスクは同一とは限らない。

## 監査・不確かさ・実装条件

12テスト合格。勾配と16更新のAdam軌道を独立したPyTorchと照合。704ペイロードのSHA256・実バイト長・復元を確認。BSpline関数の直接評価による損失再計算の最大差1.78e-15、別の白色化実装による母集団下限の最大差3.34e-16。1世界・1初期値・部分共有の全11方式を再学習し、ペイロードがバイト単位で一致した。同一コンテナ内の監査であり外部追試ではない。

統計単位は5世界。H3の減少率平均79.28%、世界間標準誤差3.75ポイント。生成分布の偏りや自然データへの外挿誤差は含まない。詳細な変数表、次元確認、大域最適値の証明は [MATHEMATICAL_CONTRACT.md](MATHEMATICAL_CONTRACT.md)。

CPU Intel Xeon Platinum 8573C、Python3.13.5、NumPy2.3.5、SciPy1.17.0、float64、BLAS1スレッド。クロック未固定・実周波数未計測。GPU・量子化・融合カーネルなし。生入力から基底を評価して全8出力を返す。展開係数768 byteとbatch64の基底6144 byteの一時領域が別途必要で、保存量減少をRAM減少とは呼ばない。

速度はbatch1/64、30ウォームアップ、100呼出×5群。batch64中央値[範囲]はrank2 0.1287[0.1091,0.1372]ms、衝突private 0.1278[0.1166,0.1285]ms。揺らぎが大きく速度優位を主張しない。学習は並行ワーカーを用いたため等時間比較ではない。初回監査の速度値はBLAS5スレッドだったためINITIALとして保全し、実設定を検査した1スレッド測定を採用した。学習ソース・モデルは変更していない。

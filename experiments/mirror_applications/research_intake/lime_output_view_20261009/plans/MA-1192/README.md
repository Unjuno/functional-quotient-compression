## 1. Native method and novelty firewall

**Actual native physical object:** native MoEP sparsely routed Attention–FFN blocks, original small GPT2/LLaMA/Gemma controls under BabyLM strict-small protocol

**Mirror insertion:** Add the low-description address `m` at **short path × layer m on shareable physical block weights while keeping native MoEP routing decisions fixed**, so that many logical specialist module paths from fewer paid physical blocks. The native model and its prior specialization/routing mechanisms remain intact. An exact-gauge or ordinary Givens/diagonal reparameterization is **M0** (no incremental Mirror-specific benefit).

## H — falsifiable hypothesis

Native MoEP path modularity can be retained when logical whole-block specialists are generated by compact m from fewer physical blocks; savings must survive native MoEP layer-level routing and original FFN-only MoE baselines at equal active compute, not merely parameter count.

## D — acceptance and rejection

**PASS (small mechanism only)**: On >=4/5 fresh heldout composed path worlds NLL within +0.02 nat/token of native MoEP and same-byte FFN-only MoE, total actual bytes <=0.85 native at P95<=1.10, and improves beyond native tied-block role embedding/same-byte LoRA.

**FAIL/M0**: Whole-block routing costs/invalid cached states dominate, native FFN MoE or ordinary tied block matches and lower active compute, Mirror m expands to full block weight size, natural BabyLM quality degrades.

**UNCERTAIN**: Native control unavailable, audit/source leakage, ambiguous task split, no actual bytes or native throughput, rank/solver numerical instability, or paired interval spans the declared gain. Full MA remains UNTESTED unless registered and independently replayed.

## C — adversarial counterexample

MoEP paper itself warns whole-block MoE may not inherit FFN-MoE scaling efficiency. Mirror may add costly runtime transformations around Attention and destroy cache compatibility.

## U — uncertainty, limits, reproduction

Router decision entanglement, sequence lengths, unverified native BabyLM checkpoint releases, hardware kernel; per-sequence rather than token as independent unit. If error components independent only, `u_c²=u_seed²+u_eval²+u_num²`; else include all covariance terms. `U_exp=k_cov*u_c` with k_cov=2 is merely indicative at n=5, not guaranteed 95%. Reproducibility requires code, exact source/checkpoint hashes, frozen split/preprocessing and every raw fresh row. Same-batch heavy-trunk recomputation of K outputs is **not** a strong baseline against native single-forward multihead. A toy aligned task success does not imply general independent functionality or 46×/64× practical compression.

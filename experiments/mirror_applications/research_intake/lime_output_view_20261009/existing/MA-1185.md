## H — Falsifiable extension

DINOv3 multi-dense-role Mirror heads must outperform an actual adaptively ranked, task-frequency-aware native FAAR decoder at matched task metric and complete physical bytes; avoid comparing to full fine-tuning alone.

## T — standalone reproduction steps

Frozen DINOv3 backbone, same spatial feature pyramid, hold out entire image/camera domains. Reproduce native FAAR PDRS adapter rank lists and TS-PD FFT spatial context; compute semantic segmentation mIoU, depth RMSE, normal angular error separately. Fit Mirror task-scale code m only in remaining native residual head, compare standard low-rank shared head, native FAAR, FiLM and K independent small heads. Serialize backbone, per-task rank schedule, FFT basis, code and all full heads; measure GPU P95 and teacher label leakage.

**Source-only development:** freeze native paper method source revision, source data/task generator and all model/checkpoint hashes; choose m rank/dim and optimizer using development 11/12/13 only. If 101–105 already used by the original experiment, choose an entirely new non-overlapping fresh [601–605], freeze that separately before any evaluation; run all fresh worlds. Native reproduction cannot silently degrade author routing, scheduling, backbone rank, kernel fusion, or source features. Use same target labels and training steps/compute and report source calibration complexity.

**Strong controls:** native full original method; same-code-count ordinary diagonal/linear projection; independent task experts/heads; no-m baseline; any applicable published PA refs above. Physical real serializer must include all shared bases, codebooks, private exceptions, routing/selector indices, headers, resident RAM/HBM copies and optional pre-folded weights.

**Metrics:** heldout useful output/retention and worst role, actual stored bytes, active MAC/FLOP, CPU/GPU P50/P95 and work amortization. One native shared trunk forward is already a direct non-Mirror baseline; comparing solely to K independent full forwards is invalid.

## D — Prior decision gate

**PASS:** at matched true useful task quality (NLL <= native +.02 nat/token or natural-metric-specific 2%), physical bytes <=.85 of native paid task/role state and runtime <=1.10 native, while strictly beating an ordinary same-byte code. Independently preregister >=10 new task-worlds and natural benchmark before general adoption.
**FAIL/M0:** a cheap ordinary factorization or native paper is better at task quality, storage or latency; only learned parametrization/gauge changes without function utility; downstream cache/route invalid or hidden oracle teacher.
**UNCERTAIN:** cannot run genuine original source/model, missing GPU/real dataset/license, five-world intervals span margins, or compiler/hardware latency unmeasured.

## C — Main counterexample

A cheaper non-Mirror code can cover the same relevant functional directions, or private off-orbit task effects demand genuine additional weights. Native trained multi-output/modular routing already provides representation/forward sharing.

## U — uncertainty

Source-task basis selection, split dependence, hardware clocks, task-gradient covariance, numerical rank/condition, and task metrics. Report every pairwise fresh world and worst task; seed/test/numerical terms combine via `u_c^2 = ∑ u_i^2` only when independent; otherwise include covariance. `U_exp = 2u_c` indicative, not a coverage-guaranteed 95% interval for n=5. Never rewrite frozen existing results or worker queue.

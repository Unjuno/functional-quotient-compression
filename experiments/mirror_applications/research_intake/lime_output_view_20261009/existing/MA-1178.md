## H — Falsifiable extension

The previously observed failed target-adapter transfer (MAT01/02) may be explained by source/shared subspace mismatch; compare LoDA task-driven shared/private decomposition and M3LoRA native multi-subspace mixer before claiming new Mirror/private rescue.

Add Mirror task core m of 4/8 coefficients and private rank1/2 under the same actual bank byte cap and optimizer. Use same target labels and training steps/compute and report source calibration complexity.

**Strong controls:** native full original method; same-code-count ordinary diagonal/linear projection; independent task experts/heads; no-m baseline; any applicable published PA refs above. Physical real serializer must include all shared bases, codebooks, private exceptions, routing/selector indices, headers, resident RAM/HBM copies and optional pre-folded weights.

**Metrics:** heldout useful output/retention and worst role, actual stored bytes, active MAC/FLOP, CPU/GPU P50/P95 and work amortization. One native shared trunk forward is already a direct non-Mirror baseline; comparing solely to K independent full forwards is invalid.

**PASS:** at matched true useful task quality (NLL <= native +.02 nat/token or natural-metric-specific 2%), physical bytes <=.85 of native paid task/role state and runtime <=1.10 native, while strictly beating an ordinary same-byte code. **UNCERTAIN:** cannot run genuine original source/model, missing GPU/real dataset/license, five-world intervals span margins, or compiler/hardware latency unmeasured.

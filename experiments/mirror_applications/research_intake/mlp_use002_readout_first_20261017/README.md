# MLP-USE-002 — Does Mirror add value on top of native task readout?

**Exploratory, frozen new-world CPU experiment completed 2026-10-17. Predeclared marginal Mirror gates FAIL.** See [research decision](../../../../docs/phase2/MLP_MIRROR_USAGE_DECISION_2026-10-17.md) and [results](RESULTS_CORE.csv).

**Insertion:** A common SwiGLU gate/up feature extractor has four paid private task-specific down/readout matrices. The Mirror candidate adds *separate* 2×2 Givens view codes to gate and up, 8 nonoverlapping rotation pairs each axis, **32 extra scalars**. Every method starts from exactly the SAME function at zero code and shares base weights + minibatches. Controls: native pair-readout only; paired native gain (32 scalars); and per-combination Givens (32 scalars).

**Data:** sklearn real handwritten digits, 1,797 images; two distinct four-view jobs over the same pixels: digit attribute BCE and noisy four-region reconstruction MSE. Three newly generated train/validation/test splits (90831-90833), 2 initializations, 4 methods, both jobs => **48 trained models** after 8 development fits on world90800. AdamW LR0.012/WD0.01 inherited from prior dev, 700 updates and batch64. Steps140/350/700 measured, checkpoint selected strictly by validation. Primary gate: <=0.95x loss and <=1.05x worst-task MSE/BCE at least 2 of 3 paired split worlds. Test performance never used to tune hyperparameters.

**Result:** Digit classification separate world median BCE: native readout 0.066327 at 15,573 B, native+Mirror 0.053357 at 16,141 B, native+gain 0.062482 at 16,141 B, native+per-pair Mirror 0.057411 at 16,141 B. **However**, matched-world strict wins for factorized Mirror versus each of the three controls were only **1/3**. Independent medians must NOT substitute for paired effects. Image reconstruction world median MSE: 0.033794, 0.033785, 0.033540, 0.033750 respectively. **Joint gates 0/3** for Mirror vs all competitors. Same CPU batch64 forward: native readout 0.0416ms vs view-Mirror 0.1600ms (unfused PyTorch eager, CPU clock uncontrolled). No Mirror-specific Pareto advantage.

**Audit:** 8 tests PASS. All **96 final/selected serialized inference payloads** independently decoded and replayed using NumPy FP64; max absolute logit diff 5.48e-5, max loss diff 4.03e-8. **Four completely retrained runs** had exact state and checkpoint SHA256 match. Source hashes were recorded before fresh evaluation and still match. Frozen analyzer writes all results successfully but ends with a KeyError during CLI reporting; `analyze_posthoc.py` changes only the display key and reproduces the same stored metrics. No post-fresh training protocol changes.

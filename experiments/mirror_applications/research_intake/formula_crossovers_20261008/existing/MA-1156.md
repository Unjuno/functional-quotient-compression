## T — independent implementation and experiment plan

Build source-only stacked J, B and SPD metrics; compute generalized eigen in the correct orientation. Reject functions outside observable range only on specified finite witness; compare random/Fisher/task-grad/Euclidean m, apply 10/50/100-step replay under same training input. **Runtime/storage:** Record CPU or GPU model/clock, dtype, backend, batch, context, 20+ warmups and >=100 timed forwards when appropriate; count exact serialized bytes, headers/codebooks/bases/private indexes, VRAM allocations, decoder prerequisites and wall latency separately. ## D — precommitted decision
PASS when >=4/5 fresh tasks show >=2% lower CE than best native simple code at same bytes/time and exact gauge twins count zero new functions, <=1pp retention loss.
**FAIL/UNCERTAIN:** Missing native reproduction, invalid algebra, model-mismatch/target data leakage, or complete byte/runtime evidence means no Mirror-specific scientific promotion. Initial PASS stays a mechanism result until independent natural-workload replication (at least 10 new task/world units).

## C — opposing hypothesis/failure mechanism
Reachability eigenvalues measure cost rather than usefulness; rank selection can be unstable, finite-step advantage may vanish at convergence.

## U — uncertainty and stopping
SVD rank, metric gauge, source witness coverage, nonlinearity and optimizer preconditioning.
For loss L, only under independent components use `u_c=sqrt(u_seed^2+u_eval^2+u_num^2)`; otherwise include covariance, and `U=k_cov*u_c` with k_cov=2 is indicative, not guaranteed 95% for n=5. Bootstrap over independent tasks/worlds, record paired seed differences, and report runtime uncertainty in seconds distinct from byte serialization.

## H — falsifiable marginal Mirror hypothesis
For a chosen functional rank r, the minimum K=r+1 simplex initialization enables stable training of useful extra Mirror states at less total serialized bytes than a no-change/width+ control; K=r+1 is not presumed optimal.

## T — independent implementation and experiment plan
Choose r in {2,4,8} after source-only function Jacobian, build K in {r,r+1,r+2,2r+2} balanced or random codes with same covariance and known parameter budgets. Split one native soft routed state into 2 children with logits a−log2 and m±epsilon*v, verify exact output at insertion. Freeze parent checkpoint, compare no-change extra training, equal-byte Dense widening, multiple code count, same code breadth, and simple gate. Sweep epsilon on dev, 3 seeds, 5 fresh task worlds. Measure NLL, old retention, optimizer time and true m/router/code bytes. Explicitly test source-world change where MN010 failed to replicate.

**Data firewall:** 3 source/dev worlds seeds {11,12,13} select rank/threshold/learning rate; disjoint held-out entire task IDs/roles in 5 fresh worlds seeds {101,102,103,104,105}, locked before reading audit. A prior original MA protocol is immutable; introduce a separate amendment and do not rewrite earlier decisions. Do not fit m using the target's independently trained oracle task delta or audit samples. Run all five fresh once if stage proceeds, no selective favorable stop.

**Runtime/storage:** Record CPU or GPU model/clock, dtype, backend, batch, context, 20+ warmups and >=100 timed forwards when appropriate; count exact serialized bytes, headers/codebooks/bases/private indexes, VRAM allocations, decoder prerequisites and wall latency separately. Fixed-update gains are learning efficiency, not capacity.

## U — uncertainty and stopping
Router symmetry breaking, epsilon selection, rank metric, independent task/world seed and training budget.
For loss L, only under independent components use `u_c=sqrt(u_seed^2+u_eval^2+u_num^2)`; otherwise include covariance, and `U=k_cov*u_c` with k_cov=2 is indicative, not guaranteed 95% for n=5. Bootstrap over independent tasks/worlds, record paired seed differences, and report runtime uncertainty in seconds distinct from byte serialization.

## T — independent implementation and experiment plan
Reproduce Stage0 K=128x16, source six Q distributions, support twelve Q and 96 audit queries; calculate rank4 audit score SVD only as oracle bound. Separately implement deployable projector calibrated on source and permitted support. Add m with 2/4 Givens angles or signed shear on source-only shared dictionary, compare same-byte ordinary linear 2/4-coefficient and native KQ. Audit softmax attention, target logits, packed size, latency, true canonical cache pointers. Five fresh OOD role families.

**Data firewall:** 3 source/dev worlds seeds {11,12,13} select rank/threshold/learning rate; disjoint held-out entire task IDs/roles in 5 fresh worlds seeds {101,102,103,104,105}, locked before reading audit. A prior original MA protocol is immutable; introduce a separate amendment and do not rewrite earlier decisions. Do not fit m using the target's independently trained oracle task delta or audit samples. Run all five fresh once if stage proceeds, no selective favorable stop.

**Runtime/storage:** Record CPU or GPU model/clock, dtype, backend, batch, context, 20+ warmups and >=100 timed forwards when appropriate; count exact serialized bytes, headers/codebooks/bases/private indexes, VRAM allocations, decoder prerequisites and wall latency separately. Fixed-update gains are learning efficiency, not capacity.

## D — precommitted decision
PASS if >=4/5 improve heldout functional score error by >=2% and whole cache bytes >=10% against best native same-byte method, without runtime >1.10; algebraic oracle-only win is not PASS.
**FAIL/UNCERTAIN:** Missing native reproduction, invalid algebra, model-mismatch/target data leakage, or complete byte/runtime evidence means no Mirror-specific scientific promotion. Initial PASS stays a mechanism result until independent natural-workload replication (at least 10 new task/world units).

## C — opposing hypothesis/failure mechanism
The earlier Stage0 native two-value linear code already cheaply compresses the bank; richer structured Mirror may only slow inference.

## U — uncertainty and stopping
Q support vs audit covariance shift, oracle/data firewall, full-rank pinv conditioning, softmax near-tie.
For loss L, only under independent components use `u_c=sqrt(u_seed^2+u_eval^2+u_num^2)`; otherwise include covariance, and `U=k_cov*u_c` with k_cov=2 is indicative, not guaranteed 95% for n=5. Bootstrap over independent tasks/worlds, record paired seed differences, and report runtime uncertainty in seconds distinct from byte serialization.

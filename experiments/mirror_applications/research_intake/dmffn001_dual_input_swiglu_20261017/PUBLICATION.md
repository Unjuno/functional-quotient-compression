## Safe reproduction
From this directory after installing requirements, in a fresh working copy:

    export OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1
    python -m pytest -q tests
    python source/train.py --phase fresh --workers 3 --steps 2400 --lr 0.018 --out /tmp/dmffn-001-fresh
    python source/audit.py --out /tmp/dmffn-001-fresh --expect 480

The auditor checks pre-fresh source hashes before replay, and requires all 480 run JSON files and serialized model payloads generated by the runner. **Do not overwrite original evidence folders.** Long follow-up uses source/long_run.py with a fixed results/long output path, so reproduce only in an isolated copy.

The compact CSV is a manually curated report summary; full numeric per-world/per-seed values are in the evidence ZIP. No natural language, GPU, external replication, automatic Transformer capacity optimization, or deployed decode-speed claims are made.

## D — decision

**PASS (new run only):** Strongest matched native and plain same-byte code do not dominate on independent quality/actual byte/real time Pareto axes, with >=4/5 preliminary fresh worlds preserving native task loss within 0.02 nat/example where applicable; report separately any justified runtime tolerance. Five fresh worlds cannot establish broad adoption.

**FAIL:** FAIL if outputs are symmetry-related only or if native single-forward linear/multi-exit controls dominate at true bytes and task quality.

**UNCERTAIN:** Missing original native source/benchmark, leaked fresh task IDs/labels, missing real serializer/cache/memory or real accelerated kernel measurements.

## C — opposing explanation

Standard shared-backbone multi-head and TabM already exploit shared inference. A role output Mirror may simply compress a tiny, low-value head rather than create independent feature capacity.

Physical storage in byte (practical integer) and latency in SI seconds; don't collapse these into a single arbitrary scalar.

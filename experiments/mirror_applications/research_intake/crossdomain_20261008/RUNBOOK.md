## Special issue triggers

- **TabM:** native BatchEnsemble rank-one fast weights can change activations before matrix multiplication; generic one-output reuse is mathematically false. Compare native optimized packed members.
- **TabPFN:** native context dependence is already trained. Do not claim all task contexts were handled by one heavy forward if support matrices differ. Compare strong posterior calibration.
- **DINOv3:** native decoder classes and task outputs may have incompatible units/dimensions. Pay task final projection; compare frozen one-backbone many-head baseline.
- **Caduceus:** native RC symmetry produces cheap orbit Views (zero new independent task information). RC-odd tasks require correct labels and strand-level splits.
- **DISCO:** ordered operator composition requires actual steps. Native Strang or beam splitting can dominate simple algebraic corrections.
- **Aurora:** one-step simultaneous variables may share processor; different horizons still need autoregressive rollout. Evaluate each physical target in correct SI units and count input IO.

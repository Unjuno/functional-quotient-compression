## H — falsifiable hypothesis

With identical pretrained W, source-only calibration and same native nonlinear activation, an m-coded shared RanLoRA residual bank preserves native individually fitted RanLoRA task loss within 0.02 nat/token and reduces the complete multi-task residual adapter state >=15% at <=1.10x P95, beating an equal-byte native linear-code or diagonal Hadamard baseline.

## Mirror insertion — minimal, precise native interface

> **Mirror insertion:** introduce small per-role m at **task-specific small Mirror m acting ONLY on the native nonlinear modulation vector / residual core, not a replacement of RanLoRA's main nonlinear path**, keeping **one frozen pretrained singular principal base plus a shared source-trained RanLoRA nonlinear residual operator bank** as the native shared physical object. Do not recreate/retrain the native method under a new name.

- Native implementation to preserve: RanLoRA's split of pretrained principal/residual singular directions, nonlinear rank-restricted residual adaptation and Hadamard modulation.
- Shared physical state paid: one frozen pretrained singular principal base plus a shared source-trained RanLoRA nonlinear residual operator bank.
- New functional coordinate: task-specific small Mirror m acting ONLY on the native nonlinear modulation vector / residual core, not a replacement of RanLoRA's main nonlinear path.
- Logical outputs: RanLoRA nonlinear residual Mirror task-coordinate bank evaluated for K independently useful tasks; gauge-equivalent or identical logits count as zero new functions.

## T — worker-independent method and runbook

**Self-contained synthetic mechanism:** Use a 64x64 frozen pretrained dense W, compute FP64 source-only singular basis; 6 naturalized source target nonlinear classification/regression tasks with common low-rank components, plus independent random private components at beta={0,0.3,0.8}. Two nonlinearity choices GELU/tanh fixed on dev. Teacher target outputs generated by independently initialized native residual adapters. Hold out whole target task generators and separate test inputs.

**Exact coding procedure:** (1) SVD W into frozen leading singular modes and tail, count all stored bases if not derived from checkpoint. (2) Implement native RanLoRA: adapt tail with low-rank factors followed by native nonlinear activation and elementwise modulation. (3) Fit source shared residual dictionary; freeze it. (4) Permit per-task support to learn small m, comparing diagonal/IA3 and rank-k ordinary linear core with identical paid state, plus optional r=1/2 private residual. (5) Train native full RanLoRA per task with same support and compute budget. (6) Audit function-space outputs, old-task interference, OOD shift and real serialized bytes; never infer quality from W Frobenius norm.

**Strong controls** (same seed/data/examples/training budget and same physical serializer):

1. Native individually fitted RanLoRA including its nonlinear Hadamard branch
2. Vanilla independent LoRA and VeRA/IA3
3. Native RanLoRA with same-byte linear/spectral compressed task bank
4. RanLoRA plus ordinary diagonal per-task scaling
5. Full independent residual upper control
6. No nonlinear residual control

**Splits and firewall:** dev seeds **11,12,13** may choose rank k, LR and early stopping; fresh full-task seeds **101,102,103,104,105** are locked and may not be inspected/tuned on. Hold out complete task families plus inputs; do not merely random-split correlated tokens/cells/sequences. Once fresh starts, execute every preregistered world. If the actual public dataset requires different splits, preregister a separate named natural stage before access. Native paper reproduction and arbitrary synthetic teachers are different evidence lanes.

**Measurements:** test per-task CE/RMSE, worst task, function-output Jacobian rank and retention, basis/code/private bytes, active GEMM/activation FLOPs and P95, percent trained improvement over native task zero-shot. Count all shared dictionaries, decoder parameters, per-role code, routing, caches/indices, resident copies, serial file headers and optional private residual. Track offline source-model training work separately. Report each model's optimizer steps/examples, actual FLOPs/MAC estimate, CPU/GPU identity, dtype, batch shape, P50/P95, warmup and synchronization, logit functionality not only weight-distance.

**Hardware:** CPU float32 64d toy; official RanLoRA LLM reproductions require GPU and exact source architecture; record fused vs eager kernel, dtype, training updates and separate factor storage.. No GPU clock/real NLL claim may be inferred from CPU fixture.

## D — frozen PASS / FAIL / UNCERTAIN

**PASS (preliminary screen only):** At least 4/5 fresh tasks mean task CE <=native RanLoRA+0.02 nat/token at <=0.85 total extra stored bytes and <=1.10 latency, with a strict benefit over same-byte ordinary task core and native diagonal Hadamard gate.

**FAIL:** Plain RanLoRA, ordinary spectral/linear bank or diagonal scaling is Pareto-optimal; source task basis leaks target test factors; active nonlinear residual code costs more than source method.

**UNCERTAIN:** Native source, task/preprocessing, real bytes or latency is missing; confidence interval contains both margins; datasets have contamination or native comparators fail. Mark BLOCKED where code/checkpoints unavailable, do not invent metrics.

**Adoption:** >=10 independent new task/seed worlds, natural realistic benchmark and quality/bytes/runtime improvement over direct native and cheap matched controls. An aligned synthetic PASS only certifies the mechanism.

## C — counter-hypothesis / falsification

RanLoRA already contains nonlinear residual modulation. Mirror codes may only reparameterize its task gate and not provide additional useful degrees of freedom; broad private tasks may be off-orbit.

## U — statistical and numerical uncertainty

Spectral degeneracy and random basis sign, singular-value skew, source-tail mismatch, optimizer LR variation, numeric activation saturation; all comparisons on heldout function outputs.
With loss measured in nat/token, `u_c² = u_seed² + u_task² + u_num²` only under independent components; otherwise include twice the relevant covariances. Expanded `U_exp = k_cov * u_c` with `k_cov=2` is indicative at n=5, not a certified 95% interval. Use paired entire-task/bootstrap intervals and report outliers without cherry-picking. Benchmark timing uncertainty in seconds separately.

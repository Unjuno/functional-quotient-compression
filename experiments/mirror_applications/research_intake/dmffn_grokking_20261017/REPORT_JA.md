# DMFFN-GROK-001 — Dual-Input Mirror SwiGLU にGrokkingは起こるか

**2026-10-17 / CPU実行済み・再現監査済み / 合成剰余演算の探索的実験。** 既存のDMFFN-001（Givens整合教師）・DMFFN-003（手書き数字から独立学習したFFN群）とは別の研究であり、過去の正式判定は変更しない。

## 結論：遅延汎化は確認したが、厳密なGrokkingは未確認

- Gate×upの構造化Mirrorは **学習入力を完全記憶した後に、未学習入力への正解率が遅れて改善**した。事前定義した「遅延汎化」に6試行中5試行が該当した。
- ただし **テスト正解率90%以上を学習後半に達成する「強いGrokking」は全30主試行で0件**。不連続的な急転換を示す確証もない。「MirrorでGrokkingを実証した」と言わない。
- 同一10,143学習パラメータ・同一43,597Bの **native gain / pair-specific Mirrorより高いテスト正解率**だった。世界単位で3/3の改善。
- **4個の独立したMLPはもっと高品質**（テスト正解率約82%）だったが、推論モデルの実保存量は163,861B。Mirrorは約73.4%小さいものの、同品質圧縮の証明ではない。
- Mirrorで **Weight Decay 0**にすると訓練は完全記憶してもテストは約9%に停滞。今回の正則化依存性は強い。しかし一般的な機構因果／長い実世界タスクへの外挿はできない。

## 1. H — 反証可能な仮説

H1. Gate側2つとup側2つの小さなMirror方向コードで、4種類の組み合わせ関数を単一SwiGLUへ押し込む際、完全記憶の後に規則的な汎化構造を学習できる。

H2. 同じ追加パラメータ数の単純なnative gainと、4組に専用コードを与えるpair-specific Mirrorと比較し、同一最適化予算で遅延汎化・テスト品質が高まる。

H3. 正則化を取り除くと、同じMirrorでも遅延汎化が弱まる。

**対立仮説**：全方式で生じる一般的な正則化依存のGrokking傾向、教師の剰余演算規則とMirror因子化の適合、共有重みの容量不足、学習率・損失曲面・データ量の差が説明する。Mirror特有の実用上の便益を示すには自然MLPでの成功、同損失に達するための学習FLOPs、実行速度が必要。

## 2. T — 凍結プロトコルと計算環境

- 有限集合：素数31で、入力 `(a,b)∈{0..30}²` の **961組**。一入力を長さ62のワンホットベクトルとして表現。4つの出力タスクは `(a+b), (a+2b), (2a+b), (2a+2b)` の各mod31で、**gate軸×up軸の4組**に対応。各入力で4タスクをすべて訓練する。したがって**未知のgate×up組み合わせは評価していない**。
- 各世界は同じ961組を擬似乱数で分割したもの：**577訓練組・384テスト組**。3分割（87011–87013）×2初期値（101,202）。3世界は**異なる入力分割であり、異なる規則・独立データセットではない**。
- SwiGLU：入力62、内部64、語彙31。共有`Wg,Wu,Wd`、2gateコード×2upコードに各16個の非重複Givens回転角。比較は通常gain、等パラメータ数のペア専用Mirror、4独立SwiGLU、同じMirrorでweight decayなし。全対照に同じ入力分割、初期シード、学習率を使う。独立MLPはパラメータ数が大きいため**品質上限対照**である。
- CPU、PyTorch2.10.0+cpu、FP32、AdamW、学習率0.005、Weight Decay0.5（負例0）、**全訓練入力を毎更新使うフルバッチ**、8,000更新、200更新ごとに訓練・テスト全件評価。3CPUワーカー並列、各1スレッド。AMD EPYC9V74、観測クロック約2.596GHz、クロック非固定、NumPy2.3.5、SciPy1.17.0。
- dev分割87001の学習曲線で機構の実行可能性を確認した後、`PROTOCOL.json`と訓練ソースのSHA-256を`PRE_FRESH_LOCK.json`に固定し、fresh分割を開いた。devでは候補ハイパーパラメータ網羅探索はしていない。fresh結果を見た調整は行わない。
- 後から追加した全共有MLPのみの6試行は、**primary結果を観察した後の事後対照**。別の`FOLLOWUP_PROTOCOL.json`と`FOLLOWUP_LOCK.json`を新規実行前に保存し、主判定には混ぜない。

### 厳密な判定ルール

**記憶の成立：** 訓練正解率99%以上に初めて到達した固定評価時点。

**遅延汎化：** 記憶成立時のテスト正解率が30%以下、その後 **1,000更新以上遅れて**テスト正解率50%以上へ到達。

**強いGrokking：** 上記条件のうち、最終的にテスト正解率**90%以上**へ到達。

8,000更新で閾値を満たさない場合は**未到達として右打ち切り**。閾値の設定は検証用の操作定義でありGrokking理論の普遍的定義ではない。

## 3. D — 実測結果

### 主評価8,000更新（3分割内2初期値平均 → 3分割の中央値）

| 方法 | テスト正解率 | 遅延汎化該当/6 | 強いGrokking/6 | 学習パラメータ | 保存推論バイト |
|---|---:|---:|---:|---:|---:|
| Gate×up Mirror | **59.99%** | **5** | 0 | **10,143** | **43,597 B** |
| 同容量native gain | 35.19% | 0 | 0 | 10,143 | 43,597 B |
| 同容量pair-specific Mirror | 35.71% | 0 | 0 | 10,143 | 43,597 B |
| 4独立SwiGLU | **82.32%** | 6 | 0 | 40,316 | 163,861 B |
| Mirror・weight decayなし | 9.18% | 0 | 0 | 10,143 | 43,597 B |

**事後対照・共有SwiGLUのみ**：テスト正解率世界中央値**28.32%**、42,901B。4つの相異なる規則に同一logitsを返すため、全4タスクを独立に表現できる構造ではない。後述の対照を主の凍結判定と混同しない。

世界対応のMirrorからnative gainを引いたテスト正解率差は、`+0.2516, +0.2933, +0.1605`。世界平均差 **+0.2351**、t(2)による**記述的**95%区間 `[+0.0664,+0.4039]`。各分割は同一規則を使用し、独立の実世界タスク標本ではないため、汎化性能への強い統計的主張には使わない。

訓練側は概ね400更新で99～100%へ到達していた。その後のテスト改善は**遅いが連続的**であり、「数千更新まで性能が完全に不変→突然ほぼ100%へジャンプ」という典型的な強いGrokkingは**未観測**。Mirrorは大きい独立モデルより小さく、native gainを明瞭に上回ったが、更新後半の改善がMirror特有の現象であると断言できない。

### 時間・容量の境界

- 1モデルの8,000更新CPU壁時間平均：Mirror **30.59秒**、gain **24.87秒**、pair-specific Mirror **29.99秒**、独立 **25.80秒**、Mirror WD0 **30.11秒**。3並行ワーカーの個別壁時間であり、一ワーカーだけの隔離性能とは異なる。クロック固定なし。
- Mirrorの実保存43,597Bは独立4MLPの163,861Bに対し**約73.4%少ない**が、テスト精度は約60%対82%。**同品質で73.4%圧縮**とは言わない。
- **学習FLOPsの厳密測定、GPU高速化、自然言語のNLL、KVキャッシュの利得は未検証**。この実験はMLPの機構分離のみ。

## 4. 監査・再現性

- 訓練とプロトコルのSHA固定は検証時にも完全一致。主評価 **30/30推論保存ファイル**のSHA256、実保存サイズ、独立NumPy+SciPy FP64の再構成出力とCE/accuracyを照合。Torch経路との最大Logit差 **4.53×10⁻⁵**。
- 事後の共有のみの **6/6保存ファイル**も独立数値経路で監査。
- 主評価のMirror1件とgain1件を、それぞれ最初から**8,000更新完全再学習**。全41評価時点の記録と保存ファイルSHAが完全一致。
- **7件の単体テストPASS**。同セッション・同環境再現であって外部の独立第三者追試ではない。
- 生の結果は`results/fresh`と`results/tied_followup`、開発は`results/cal_*`。完全証拠ZIPには保存モデル・訓練曲線・監査ログを含む。推論ペイロードは不正な容量推定ではなく`torch.save(state_dict + config)`の実バイトで計測。

## 5. C — 反例と混同を避けること

1. **遅延汎化 ≠ 典型的なGrokkingの完全再現。**90%到達を伴う強いGrokking 0/30。この実験は他文献の「Grokkingを必ず再現する」設定そのものではない。
2. **独立MLPも6/6で遅延汎化する。**Mirrorだけの学習機構と結論できない。Mirrorは**同容量のgainとpair-specific Mirror**に勝ったという限定的な結果。
3. **正則化の寄与は大きい。**Mirror WD0は記憶のまま試験性能が低い。Weight Decayが万能または唯一原因とは言えない。
4. **全4組の規則を学習した**。DMFFN-001の3/9未学習の組み合わせ汎化やDMFFN-003の自然画像の未知タスクとは別問題である。
5. 3つの世界は新しいランダム分割にすぎない。自然言語、手書き数字、学習済みTransformerの機能関係への適用は未確認。
6. 既存DMFFN-003の自然画像では長時間学習でBCEが悪化した結果もあり、剰余演算での遅延汎化をそのままTransformerに外挿しない。

## 6. U — 不確かさと次の実験

不確かさ：3分割×各2初期値と同じ規則集合、異なるCPUスケジューリング、FP32、同一LRがnativeに最適とは限らない、固定8,000更新という右打ち切り。標準誤差は上記世界差の標本分散から算出し、tの包含係数**4.303**はdf2の**記述的**設定。実世界へ外挿するモデル不一致は統計的区間に含まない。

**次の凍結課題（実施していない）：**
- 40%,60%,80%学習データ比×Weight Decay掃引×20,000更新で、遅延汎化の出現時点と強いGrokking条件を再検査する。LRをdevで各方式公平化。
- 4組の一部を未学習に残す「gate×up未見組合せ」を独立課題にし、Mirrorとgainを同容量比較。これを入力ホールドアウトと混同しない。
- Mirrorコード、共有重み、埋め込み等のフーリエ周波数集中・勾配角度・符号/ノルムを追跡し、規則構造がどこに獲得されたかを調べる。
- 手書き数字・自然言語での遅延汎化は別実験とする。

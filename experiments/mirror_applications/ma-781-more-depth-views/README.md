# MA-781 — MoRE shared expert pool with depth views

Status: **FAIL** for Mirror-specific value (synthetic operator screen).

## Fact

On a 4-layer × 4-expert synthetic bank, the independent role bank uses 4,271 B at zero heldout error. Hard expert tying uses 1,418 B at nRMSE .02423. The MoRE-style additive depth/expert embedding uses 2,814 B at nRMSE .02905. A rank-2 bilinear shared-basis code uses 2,803 B at nRMSE .01866, saving 34.4% bytes vs independent but requiring 194 vs 64 MAC/role. Mirror and native bilinear factorization have exactly equal payload hash, bytes, output error and MAC count. Calibration used 44 nonlinear least-squares solver evaluations; no SGD updates were run.

## Interpretation

Factorized depth×expert codes recover the designed heldout role interactions where hard tying and additive depth/expert embeddings miss the .02 quality gate. The result costs about 3× the matrix MAC proxy, and the apparent Mirror gain is exactly ordinary bilinear shared-basis factorization. Against the additive MoRE-style control, the payload is only 11 B smaller and compute is higher. No Mirror-specific or trained-MoRE improvement is established.

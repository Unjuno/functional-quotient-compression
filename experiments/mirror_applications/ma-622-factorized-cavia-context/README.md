# MA-622 — Factorized CAVIA task context

Status: SCREENING  
Evidence lane: MECHANISM / META-ADAPTATION / HELD-OUT COMPOSITION / ACTUAL BYTES  
Base commit: `739ba2ed`  
Prior art: PA129 CAVIA

## Hypothesis

**H:** In a 4×4 compositional task family, a shared CAVIA context vector addressed by two small factor codes can reconstruct held-out task combinations with lower serialized per-task state than independent CAVIA contexts; it must also beat a native factorized/direct-angle CAVIA context to support a Mirror-specific claim.

## Mirror insertion

> **Mirror insertion:** this experiment adds `m=(task_factor, role_factor)` to CAVIA's task-context interface so that a shared context can produce task-combination-specific functions without storing one full context vector per task pair.

- Native method: shared linear predictor with a task-specific CAVIA context fitted from support examples.
- Exact insertion point: the context vector `c` in `f(x; θ, c)`, generated for each factor pair from one shared context and two factor-indexed rotation coordinates.
- Persistent state: shared context seed, four task-factor angles, four role-factor angles, and 4×4 factor indices.
- Cheapest controls: native direct-angle factorized CAVIA and additive low-rank factorized CAVIA contexts.

## Task and controls

A fixed shared linear model receives 16-dimensional inputs and an 8-dimensional CAVIA context. There are 16 tasks arranged as 4×4 factor combinations. Four diagonal combinations are held out; every factor value still appears in the 12 training combinations. Each task has 16 support and 128 disjoint audit examples.

Two predeclared task worlds are measured in each seed:

1. **Aligned:** task contexts are generated by composing two factor-indexed Givens rotations of one shared context vector.
2. **Private interaction:** the same factor structure plus a fixed-amplitude pair-specific residual. This tests where the factor code needs private context state.

Controls:

- shared model with no task context;
- independent CAVIA context fitted from each task's support, including held-out task supports;
- factorized Mirror context `R(a_i)R(b_j)c₀`, trained from the 12 visible combinations and evaluated on four held-out combinations;
- native direct-angle CAVIA using the same factor angles and equations;
- native additive factorized CAVIA (`u_i+v_j`) fitted to visible task contexts.

Factor indices are provided as task metadata, not inferred from the examples. They are charged in the inference payload. This is a mechanism screen for compositional context geometry, not task-free routing or meta-training.

## Gates

**PASS for useful factorization:** both development worlds/seeds achieve held-out aligned nRMSE ≤0.05, improve nRMSE by at least 20% versus the shared/no-context model, and use ≤75% of the independent CAVIA task-state bytes. Complete payload bytes are reported for every method.

**FAIL for Mirror-specific attribution:** direct-angle CAVIA matches Mirror outputs and serialized context state, or native additive factorized CAVIA matches quality at equal or lower bytes/compute. A private-interaction failure is separately reported as a boundary; it does not erase an aligned result.

Fresh seeds 62211–62213 stay sealed if the development result aliases a native control or misses the aligned quality/storage gate.

## Tuning and compute

Development seeds: 62201 and 62202. Fresh seeds: 62211, 62212, 62213, frozen before any run. Geometry, held-out combinations, factor dimension, residual amplitude, support size and gates do not change after development starts. No optimizer updates are used; support-context fitting and factor fitting are reported as solve/evaluation counts and wall time.

## Storage and boundaries

The actual `.npz` inference payload includes the shared base predictor and context basis, each method's context/factor state, factor indices, schema and metadata. Report both complete payload bytes and task-state-only bytes. This is a synthetic aligned linear task-context screen. It does not establish natural few-shot learning, trained CAVIA performance, language quality, or general meta-learning capacity.

# MA-330 — Tensorized KV cache reconstruction

Status: PROMISING, narrowly. Prior art: PA08 MLKV and PA35 Tucker matrix banks.

## H

One shared physical K/V cache plus layer/head Mirror views may recover logical role differences with fewer cache bytes. Compare MLKV hard sharing and generic Tucker/PCA state; count decode-time reconstruction cost.

## T

8 layers × 2 KV heads, 32 cached tokens, head dimension 16. Compare full independent cache state, one shared MLKV-style state, shared Mirror bases plus per-role angles, and generic rank-2 Tucker/PCA. Test aligned and independent role caches. Development worlds 33000–33001; fresh 33010–33012; three seeds each. Measure held-out query attention contexts, cache NRMSE, actual bytes and materialization cost.

## D

Pending development/fresh runs.

## C

Aligned states are generated by the same Givens rotations; generic low-rank role factors may match them. Independent cache states may need private storage.

## U

No autoregressive decode, language perplexity, real hardware bandwidth or trained attention evidence.

**H — Hypothesis:** one shared K/V cache tensor plus per-layer/head Mirror coordinates reconstructs aligned role states with lower payload bytes while preserving attention context; independent roles reveal when private state is needed.

**T — Experiment:** 8 layers × 2 KV heads, 32 cached tokens, head dimension 16; three fresh worlds × three seeds, aligned and independent cache states. Controls: full independent cache, hard-shared MLKV, rank-2 generic Tucker/PCA, and Mirror role views. Payloads serialized as fp16 with metadata; MAC proxy, encode time, materialization time, cache and context NRMSE recorded separately.

**D — PROMISING, narrowly:** fresh aligned means: Mirror 2,287 B / cache NRMSE 4.27e-4 / attention-context NRMSE 6.02e-4; generic PCA/Tucker 6,502 B / 4.27e-4; full cache 32,909 B / 3.12e-4. Mirror uses 64.8% fewer bytes than PCA/Tucker and 93.0% fewer than full cache, below the 0.05 context-error gate. Hard-shared MLKV is 2,188 B but context error is 0.999. Mirror materialization is 0.846 ms vs PCA/Tucker 0.051 ms, both with 32,768 estimated MACs; encode time is 0.451 vs 0.674 ms. Independent-cache Mirror context error is 1.366, PCA/Tucker 0.938, full cache 0.000300.

**C — Counter-hypothesis:** the teacher is generated by the same Givens rotations used by Mirror, and the unusually low payload is an aligned-orbit result. The generic factorization is also much faster to materialize. This does not establish a practical KV-cache method.

**U — Unconfirmed:** autoregressive decoding, language NLL/perplexity, real attention checkpoints, bandwidth/VRAM, optimized kernels, and naturally occurring cache-role alignment.

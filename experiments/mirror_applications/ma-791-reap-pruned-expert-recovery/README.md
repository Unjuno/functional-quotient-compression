Status: **FAIL** for Mirror-specific value.

## Fact

Eight retained 12×12 experts have eight paired pruned experts. At σ=0, routing to the retained partner uses 5,408 B and heldout pruned-expert error .0678. Adding a rank-1 shared residual view recovers heldout error to `1.90e-8` at 6,403 B vs 9,001 B independent (28.9% fewer); the one-time reconstruction proxy is 1,152 MACs. Mirror and native PCA payloads/metrics match exactly. At σ=.05, shared rank-1 heldout error is .302; private rank-4 lowers it to .149 but costs 10,103 B vs 9,002 B independent.

## Interpretation

For paired experts whose differences lie in one shared direction, a code can recover useful pruned distinctions while retaining a byte saving after all map and ID metadata. With private variation, the shared code fails and a small private fallback still exceeds independent storage. The result is standard PCA residual recovery, not a Mirror-specific effect.

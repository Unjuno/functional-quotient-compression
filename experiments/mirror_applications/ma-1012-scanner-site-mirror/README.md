# MA-1012 — Scanner-site calibration Mirror code

Bounded synthetic multi-coil mechanism screen for a frozen reconstruction prior calibrated with site-level coordinates. The registered target is deployment across held-out scanners/protocols; this run uses analytic coil maps, Cartesian masks and synthetic phantoms because no acquired fastMRI/PREDICTOM or scanner data/checkpoint is present in the workspace.

Controls include ordinary FiLM calibration and independent full-prior site adaptation. See `PROTOCOL.json` for frozen conditions and gates. This is not a VarNet or clinical reproduction.

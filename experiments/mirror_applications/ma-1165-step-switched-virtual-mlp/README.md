# MA-1165 — Step-switched nonlinear Mirror for one-vector virtual MLPs

**Status: SCREENING plan; no empirical superiority claimed until RESULTS_CORE.csv and VERIFICATION.json are produced.**

**Mirror insertion:** this experiment adds a step-indexed nonlinear orthogonal Mirror to the virtual-weight generator of a single learned physical coefficient vector, so distinct recurrent MLP stages can use different virtual weights without storing full independent MLP matrices.

## Motivation, preserved parent operator

MA-1163 and MA-1164 use one `nn.Parameter` coefficient vector to generate all weights of an ordinary MLP via fixed orthogonal embedding, `Q^{-1} tanh(Qz+b)`, and residual recursion. Their K/R and compressed teacher-weight experiments **did not demonstrate Mirror-specific wins** over simple orthogonal controls. This experiment preserves the operator family and applies the resulting virtual MLP separately at successive functional steps. It does **not** replace the one-vector MLP with a generic activation-space rotation.

For fixed `d=8, hidden=16, out=8, n_virtual=280` and `m=192` learned coefficients:
`z_0 = O Pad_I(u)`;
`z_{s+1}=z_s + 0.16 Q_s^T tanh(Q_s z_s + b_s)`;
`w_s = z_{s+1}`;
`h_{s+1}=h_s+(0.40/T) MLP(h_s; w_s)`.

`O` and `Q_s` are deterministic, invertible orthogonal programs (Givens, Householder, permutation). Switch mode uses distinct Q and bias by step. Same mode uses identical Q and bias at all steps, but operates on evolving z, so weights can still change. Tied, linear-null, learned-small-gain, and untied native controls separate the claims.

This is **one learned physical coefficient vector**, not one scalar and not one numerical value including deterministic program state. Gains in the gain control and all untied weights are counted. This study is functional recurrence: `T` is the number of executions of a virtual MLP, with one nonlinear Mirror generator update preceding each step.

## Primary falsifiable questions

1. Does the switched Mirror achieve lower held-out error than the *same* Mirror under identical learned coefficient count and execution depth?
2. Does it exceed cheaper, non-Mirror step conditioning (linear null and learned gain/shift) when actual inference payload bytes and MAC proxy are charged?
3. Is the benefit limited to data generated by the same Mirror family (aligned), versus independently generated teacher MLP stacks (out-of-family)?
4. Does code swapping or step ablation cause task-specific output changes, and do step-wise gradients conflict?

## Primary controls / status

- `tied`: one shared virtual MLP (no generator iteration).
- `same`: repeated nonlinear generator with identical Q and bias.
- `switch`: nonlinear Mirror generator with step-varying Q and bias (**candidate**).
- `linear`: remove tanh/bias in the Mirror program; Q^T Q cancels exactly, a scaling-only null.
- `gain`: same shared u with learned step-level scalar gain/bias (stronger simple conditioning; count 2T extra floats).
- `untied`: independent trainable ordinary MLP per functional depth (upper control; more bytes).

Primary task: teacher-defined `aligned` and `independent` smooth nonlinear vector regression. **Aligned is a mechanism positive control, not evidence of natural model compression.** Train on fresh Gaussian inputs, measure independently seeded held-out and shifted-distribution inputs.

All models train from input/output only. Intermediate teacher states or teacher weights are not training targets. Loss is normalized by teacher displacement from the input to avoid identity-mapping shortcuts. Dev choices never inspect audit labels. At fixed training updates no capacity claim; storage cost is serialized bytes, not coefficient count.

# MA-1166 Phase C — NO PRUNING evaluation (preregistered)
Date: 2026-10-20 (JST)
Status: FROZEN BEFORE PHASE-C CODE OR TRAINING.

## Question
Does keeping every virtual-edge and Mirror candidate throughout training and inference improve fresh task accuracy at a fixed 253 learned scalar coefficient budget? Is full-edge compute better than stochastic sampled-edge compute, and does nonlinear inverse-Mirror decoding beat a direct affine decoder or a native MLP?

**No edge, Mirror, Loop, physical coefficient, or node is deleted. No L0/L1 gate/structure penalty. No threshold or mask is applied at inference.**

## Supergraph
- Input/state d=6, 6 unrolled node events (3 identities x2 passes); every ordered node event pair including input event 0 to events 1..6; 21 pairs; three Mirror addresses per pair; **63 edge-view virtual MLPs** each 6->8 (tanh)->6 (110 logical scalars). All 63 remain in full inference.
- Each edge's virtual 110-vector is decoded on-demand from ONE physical trainable tensor with 64 shared core coefficients, 63 gate logits, 126 view-specific coefficients = exactly 253 learned FP32 scalars. Learned gates do not incur pressure; sigmoid strengths are not converted to binary. Core is embedded with a fixed seeded orthogonal-style matrix, transformed by two seeded Householder reflections with two learned direction codes then tanh and inverse reflection to make the native virtual MLP weights. Exact learned code and seeded program cost counted.
- Tensor execution uses full skip graph, not just adjacent layers, and computes 3 views of each allowed edge. Input-dependent attention is not part of the tested graph.
- Controls: (1) same-253-coefficient direct affine virtual-weight decoder; (2) matched 253-scalar native residual MLP 6->19->6; (3) larger six-block native residual MLP as an upper-context control.
- Full vs sample comparison: during train only select each candidate with p=0.5, with scaling 1/p, but at evaluation restore **all** edges (no pruning). Nonlinear network outputs mean the sampled training objective is not the same as full supergraph loss.

## Data and training
- Two synthetic teacher families: *aligned* teacher explicitly generated by the same Mirror decoder with sparse teacher-edge contribution (aligned positive control, student sees only inputs/outputs), and *independent* teacher with independently generated MLP weights on a fixed subset of edges (unaligned more realistic negative control).
- Seeds: 421, 433, 447 (never used in MA-1165/1166 Phase A/B).
- Train examples 2,048, development 1,024, fresh 1,024, OOD 1,024. Independent input draws. Output target is teacher output and task normalized error relative to identity predictor ||Y-X||².
- CPU FP32 torch with single-thread compute, Adam learning rate 0.015, updates 400, batch128, identical steps for all methods. Use no early stopping on fresh; report last-step and optional dev-best epochs selected without fresh.
- One paired comparison per seed×world: mirror-full, mirror-sample, affine-full, affine-sample, native-253, native-660. Total 36 runs. Do not claim near-convergence from this screen.
- Save all student physical checkpoints, program+seed code, metrics and run environment, including loss curves and full graph edge counts and replay SHA. Isolated b1 inference timing and actual serialized inference payload bytes for all methods.

## Decision
No-prune learning **feasibility** if Mirror-full beats identity baseline 1.0 NMSE on >=5/6 worlds/seeds, with finite gradients and 63 active evaluated graph edge-view transforms. Mirror advantage over affine requires paired quality win >=5% in >=4/6 world/seed settings at matched bytes and no more active compute. No-prune full-vs-sample winner requires >=4/6 paired quality wins and report compute/time. Native comparison is descriptive and never skipped.

## Important constraints
This is a *new independent run* and no Phase A/B scores are imported as fresh evidence. This is a synthetic fixed-update screen, not a global-architecture or extreme-compression proof. Mirror-specific runtime cannot be treated as free. Feature-gate values near zero do not count as pruned or removed; all 63 edge/view transforms still execute. End-of-training physical compression is **not performed**.

# MA-1166 Phase E — synchronous all-to-all virtual Mirror graph vs serial graph

**Date:** 2026-10-20 JST. **Status: preregistered before any Phase-E learning.** Phase A–D kept unchanged. No pruning, routing sparsity penalty, or use of test/fresh examples to select hyperparameters.

## Central experiment
The request is NOT 126 independent virtual MLP parameter objects. A **single physical parameter tensor of exactly 442 scalar coefficients** generates 126 virtual **6→8→6 weight vectors**, and all 126 functions receive gradient via a single backward call. Compare an all-to-all synchronous (Jacobi) recurrent graph and an asynchronous depth-ordered (Gauss-Seidel/DAG) graph, with equal physical coefficients, not assume equality of active compute.

### Candidate wiring
1. **SYNC**: nodes 1..6; input source node0 plus all ordered source-destination pairs among nodes1..6 (including self, backward, and long-range skip): (6 +6×6)×3 distinct Mirror addresses =126 candidates PER update. Start h_1..h_6=0; input state h_0=x. All messages at step t use ONLY h^(t), so all 126 edges can be batched simultaneously. Three Jacobi steps; output x+h_6^(T).
2. **SERIAL**: nodes1..6 in topological order; all forward pairs from nodes0..5 to later nodes, 21×6 virtual Mirror addresses =126 edges. Compute each node sequentially as in Phase C. Compare 1 serial graph pass against 1 sync step at equal number of virtual edge evaluations and vs 3 sync steps to expose compute trade-off. Same 442 trainable scalars.
3. Mirror virtual-weight decoder: one shared physical core u∈R^64 and edge-conditioned 2-scalar Householder orientation code for each of 126 edges, plus 126 sigmoid edge-strength coefficients. Original nonlinear WEIGHT-space Mirror: z_e=z_base+fixed_e+0.65 Q_e^-1 tanh(2.2 Q_e(z_base+fixed_e)+fixed_bias_e). Virtual tensor weights are never learned/stored independently.
4. Affine comparator: same learned 442 scalars, same fixed z_base and edge program, but direct nonlinear/non-Mirror feature codes; separate paired `affine_sync3` and `affine_serial` controls.
5. Native 442-parameter residual 6→33→6 MLP (+ 7 output gate scalars). **442 learned scalars in every method**; no pruning. Fixed random decoder buffers reconstructed by program seed; calculate storage for seed, descriptor, weight state, code/program separately.

## Registered training and evaluation
- Task teachers: (A) `sync_aligned`, generated from an independently sampled Mirror-SYNC3 teacher with frozen program, student never sees teacher internals; (B) `serial_independent`, generated by independent ordinary virtual MLPs in a sparse long-/short-range serial DAG.
- Seeds **461,463,467**, absent from earlier MA-1166 trials. For each seed, independent train/dev/fresh/OOD samples, teacher target a 6D vector. 2,048 train, 1,024 development, 1,024 fresh, 1,024 OOD, X∼N(0,0.9²), OOD sigma1.5. Train with MSE normalized by residual teacher-vs-input target, evaluate both normalized MSE and raw MSE.
- Six methods: `mirror_serial`, `mirror_sync1`, `mirror_sync3`, `affine_serial`, `affine_sync3`, `native442`. 2 worlds×3 seeds×6=**36 conditions**; CPU torch FP32, single thread, Adam lr0.015, **300 gradient updates**, minibatch128. No tuning on fresh. Evaluate train/dev/fresh/OOD after final step.
- Tests before training: exact 126 counts for sync/serial, gradient reaches one θ tensor core/gates/codes for all edge classes, synchronous vectorized kernel = slow reference forward AND gradients, no future-step state leakage, deterministic decoder reconstruction, physical parameter count, channel dimensions and sampled-edge masking equivalence for probability1.
- Run matched total step calculations: SYNC1:126 per example; SYNC3:378; SERIAL:126 (although serial depth6). Report computational advantage as parallel critical path (sync3=3 sequential state steps, serial=6 sequential node steps), **not actual GPU latency evidence**. Measure single-thread batch1 eager CPU time; no GPU claims.
- Preserve every trained 442-coefficient checkpoint plus data generator deterministic seeds, outputs SHA, serialized deployment bytes, full command, JSON/CSV and tests.
- Pair-level conclusions only; 300 updates = fixed-budget mechanism screen, **not** capacity at convergence. If full 36 cannot finish, mark subset.

## Falsifiable gates and limitations
- Parallel gradient mechanism PASS if complete 126-edge vectorized reference matches output/gradient (FP32 atol5e-5) and all 442 trainable scalar coefficients have finite gradients, including edges that begin from uninitialized hidden nodes (after 3 updates).
- Quality WIN over serial if mirror_sync3 beats mirror_serial on >=4/6 paired fresh NMSE, **with explicit 3× edge evaluation cost**; runtime claim requires real throughput gain.
- Mirror specificity requires mirror_sync3 outperform affine_sync3 by >=5% fresh NMSE on >=4/6 and not exceed its actual payload/compute. Otherwise FAIL.
- Avoid overclaim: 126 logical virtual weight arrays ×110 coefficients =13,860 mapped weights, but continuous trainable DOF<=442; per-edge codes+gates are 378/442 (85.5%) and not free. 3 synchronous steps need 3 serial barriers and do not remove all recurrence. No transformer LM validation or true convergence claim.

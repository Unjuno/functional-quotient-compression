# MA-1166 — Fully enumerated Mirror/Loop/pointer supergraph, soft routing and sampled-compute control

**Status:** preregistered CPU mechanism screen, no results yet. **Date:** 2026-10-20 JST.

**Mirror insertion:** this experiment adds deterministically addressable nonlinear Mirror views `m_e` to the *virtual MLP weight decoder of every candidate graph edge* so that a single learned physical coefficient vector can supply many logical edge functions without storing independent edge MLPs.

## H: Falsifiable hypotheses
H1: a virtual DAG with **all** forward connections, three view choices per connection and six unrolled node events (3 node identities x 2 Loop passes), trained with continuous gates, can be discretized after training without losing more than the preregistered development quality tolerance.
H2: sampling only some candidate edges during stochastic training reduces active edge computation while retaining competitive final fresh quality against identical full-edge training.
H3: the nonlinear inverse-Mirror weight decoder improves quality/bytes/runtime over an equally sized native affine-coded shared basis. This is **not assumed**; past MA-1163/1164/1165 results were negative.

## T: Frozen screening protocol
- Node events 1..6 (two passes of three reusable module identities), event 0 input; every directed i<j pair, including 1->3 and 1->6, and 3 deterministic views per pair: 21*3=63 candidates, no intermediate architectural pruning while training.
- Input dimension 6, virtual MLP 6->8 (tanh)->6; 110 native weights per edge, shared physical core 64 floats; one physical parameter object containing core, 63 edge gate logits and two scalars per edge (=253 physical learned coefficients).
- Nonlinear weight decoder uses two seeded Householder mirrors, tanh, inverse mirrors and learned view codes; matched affine control uses the **same 253 coefficients** and seeded feature codes without Householder nonlinear decoding.
- Learner variants: `mirror_full`, `mirror_sample`, `affine_full`, `affine_sample`, `independent_full` unrestricted upper bound. Sampled branch samples each possible edge independently with probability 0.5 and divides surviving contributions by 0.5, estimating graph preactivations, **not guaranteeing unbiased full-network outputs**.
- Teacher families: `aligned` generated by same Mirror family from another seeded core on selected edges; `independent` generated by independently weighted MLPs on selected edges. Train/dev/fresh inputs independently generated from separate known seed streams and disjoint examples.
- Seeds 211,223; 180 Adam optimizer updates; batch128; train2048, dev1024, fresh1024; FP32 CPU; output loss normalized against identity-input teacher residual.
- Gate pressure ramps after the first quarter of updates; **no hard deletion during training**. Postfit threshold sweep on dev and optional core-coordinate masking; once chosen, evaluate fresh only once.
- Record mirror insertion/swap checks, all-vs-sampled active edges and runtime, post-prune fresh, serialized inference payload bytes and checkpoint replay. Program size and deterministic seeds separately accounted.

## D: Decision gates
Mechanism PASS requires correct enumeration (63 edge/view candidates), differentiable core/gates/codes, sampled compute less than full and verified final serialization/replay. Mirror-specific PASS requires improvement over affine control at matched learned scalars *and* actual inference bytes and active compute across both worlds/seeds. Compression PASS requires post-prune fresh quality within 5% relative of pre-prune on >=3/4 mirror world/seed pairs, with lower actual payload bytes. Otherwise FAIL/INCONCLUSIVE by scope. Fixed-update wins do not establish capacity.

## C and U
High candidate fan-in, nonlinear interactions and sample-training mismatch may corrupt convergence; local gate minima may keep useless routes; dense seeded decoder code may exceed learned payload; latent aliasing might make affine equally strong. The aligned family is an oracle-feasibility positive control, not a natural task. Independently generated teachers are still synthetic, not LM evidence. End-to-end convergence, true language loss, GPU performance and precise global structure search remain open.

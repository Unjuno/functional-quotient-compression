# PA303 source provenance

Paper: MoDL: Model Based Deep Learning Architecture for Inverse Problems, https://arxiv.org/abs/1712.02862.

Official repository inspected: https://github.com/hkaggarwal/modl at commit `2b02b9b48348eb44a56398f7b15d7dc556771edc`. It implements a residual CNN shared across unrolled steps and conjugate-gradient solves for the MRI normal equation. The repository's root does not declare a code license and its implementation targets TensorFlow 1.x. No source code or model weights were copied. `source/modl_torch.py` is an independent compact PyTorch implementation of the published equations for this synthetic mechanism screen.

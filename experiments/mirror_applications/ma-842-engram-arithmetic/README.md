# MA-842 — Simultaneous engram arithmetic

Status: SCREENING. Prior art: PA227, AI Engram.

H: Signed/sparse superposition of compact Mirror memory codes preserves simultaneous retrieval, composition and erasure with >=25% fewer complete bytes than independent traces and beats native factorization.

Twenty shared and private memory traces are composed in 256 signed mixtures of two to eight memories. We compare raw addition, Mirror codes, native PCA and residual ranks. Combination count is an evaluation set, not a capacity claim. All bases, codes, Fisher state and IDs are charged. Synthetic associative memory only. See [PROTOCOL.json](PROTOCOL.json).

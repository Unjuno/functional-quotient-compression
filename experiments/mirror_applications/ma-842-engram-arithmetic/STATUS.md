## Fact / Interpretation / Hypothesis

- **Fact:** At rank3, all measured causal checks and 256 mixture outputs are preserved, but byte savings are 9.2% and compute proxy is 1.61x raw addition. Native factorization hashes match Mirror exactly.
- **Interpretation:** Compositional code arithmetic does not add functions beyond ordinary addition in this model. Exceptions force basis growth and reduce the storage frontier.
- **Hypothesis:** A future advantage would need a representation where useful mixtures can be decoded without paying dense raw addition or a native low-rank factorization equivalent; this screen finds none.

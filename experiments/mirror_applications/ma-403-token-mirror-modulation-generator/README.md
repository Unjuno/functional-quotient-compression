# MA-403 — token-wise Mirror modulation generator

Status: **FAIL at the frozen development screen**.
Evidence lane: MECHANISM / STORAGE / RUNTIME.
Prior art: PA63 (FiLM), PA64 (SPADE/spatially adaptive normalization).

## H — Hypothesis
A token-position-generated Mirror coordinate can express smooth token-specific rotations over one shared nonlinear feature block with lower held-out error and payload than token-wise FiLM.

## T — Treatment
A shared frozen 16D feature block maps token inputs. Eight Givens angles vary affinely with position `p`; train positions are `[0,0.8)`, held-out positions `[0.8,1)`. Five controls: global FiLM, token-wise affine FiLM, token-wise rank-one conditional residual, Mirror angle generator, and full-affine generator. Two development seeds (40301/40302), 4096 examples, 400 updates, batch 1024. Fresh 40311–40313 remained sealed. Payload is deterministic NPZ with FP16 shared weights and all conditional state plus metadata.

## D — Decision: FAIL
Both seeds had excellent held-out Mirror NRMSE, but failed payload and throughput gates.

- Seed 40301: Mirror NRMSE 0.000370 versus token FiLM 0.612972; payload 2,136 versus 2,581 bytes (ratio 0.828); versus full-affine 3,604 bytes (ratio 0.593); throughput 0.255x token FiLM.
- Seed 40302: Mirror NRMSE 0.000570 versus token FiLM 0.728978; payload 2,129 versus 2,574 bytes (ratio 0.827); versus full-affine 3,601 bytes (ratio 0.591); throughput 0.049x token FiLM.

Thus the frozen byte gates (<=0.75x token FiLM and <=0.10x full affine) and throughput gate (>=0.80x token FiLM) failed in both seeds. No fresh testing proceeded. `source/verify.py` replays all ten metrics from the serialized payloads.

## C — Strongest counter-hypothesis
The target itself is generated by an affine-in-position Givens code, so the quality advantage is a deliberately aligned mechanism test, not evidence for arbitrary token-wise functions. The common shared feature-block bytes dominate the compact generator's total payload at this small width.

## U — Unknowns
Natural token tasks, larger shared blocks, optimized inference kernels, and fresh seeds remain untested. This narrow synthetic FAIL does not imply that token-wise Views are generally ineffective.

## Fact / Interpretation / Hypothesis
**FACT:** both seeds met the quality target by a large margin and missed byte and CPU throughput gates; payload and metric replay passed; no fresh data were accessed.

**INTERPRETATION:** token-wise Mirror codes compactly represent this smooth structured family, but marginal code savings do not clear total serialized byte thresholds, and the current trig implementation is slower than FiLM.

**HYPOTHESIS:** wider shared physical blocks may amortize code state better; this needs a separate frozen experiment and should compare optimized kernels.

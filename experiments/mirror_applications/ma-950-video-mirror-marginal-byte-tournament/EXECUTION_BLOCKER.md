# Execution blocker

The tournament requires identical contents and bitrate points, real native bitstreams, decode FPS and peak VRAM across established codec families. Only MA-939 has runnable evidence, and it is one HNeRV Bunny model-payload compression screen, not bpp. NerVast, DCVC-UF/RT and DCMVC native weights/bitstreams are unavailable; no CUDA GPU exists. A cross-paper table would be incomparable.

Disposition: **UNTESTED**, not FAIL.

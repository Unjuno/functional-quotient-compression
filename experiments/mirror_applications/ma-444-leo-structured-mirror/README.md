# MA-444 — LEO decoder versus structured three-angle Mirror map

Status: SCREENING  
Evidence lane: MECHANISM/STORAGE/RUNTIME  
Branch: `research/ma-444-leo-structured-mirror-20261008`  
Base commit: `1d78e9e`  
Prior art: PA76 (LEO)

## Hypothesis

H: On held-out few-shot linear tasks generated by a three-angle rotation orbit, a 3D Mirror latent will approach a matched-width learned LEO decoder with fewer actual bank bytes and acceptable adaptation time, while outperforming rank-3 additive control. If direct native Givens conditioning reproduces it, the effect is structured conditioning rather than Mirror-specific value.

**Mirror insertion:** this experiment adds a three-value support-adapted latent `z` to a shared nine-coefficient predictor so distinct task functions can be reconstructed without storing a separate decoder or full vector per task.

## Task and controls

The task is a 9D linear predictor whose per-task coefficient is generated by three disjoint Givens rotations of one shared template. Each condition sees the same task episodes: 160 first-order meta-updates × 8 training tasks, then four inner updates from 12 support examples and 40 query examples per held-out task. The primary comparison is a learned 3→24→9 LEO MLP decoder versus the 3D rotation map. Additional controls are shared/no-adapt, full 9D FOMAML, rank-3 additive latent adapter, native direct Givens conditioning, and independent support-set least squares.

Two seeds (44401, 44402) are development-only. Fresh seeds (44411–44413) stay sealed unless all frozen gates pass. Every inference bank has 16 tasks and is measured as the actual uncompressed `.npz` archive with all arrays and schema bytes.

## Gates

See `PROTOCOL.json` for exact quality, byte, and end-to-end runtime thresholds. The native Givens condition intentionally tests exact parameterization alias; its presence does not reduce the requirement to compare with learned LEO and rank-3 controls.

## H — Hypothesis

The frozen hypothesis and gates are in `PROTOCOL.json`: a three-angle View should approximate a matched-dimension learned LEO decoder with ≤75% actual payload bytes and acceptable adaptation runtime, while beating rank-3 additive adaptation. Native Givens conditioning and independent fitted task vectors adjudicate attribution and task learnability.

## T — What ran

Two development seeds (44401, 44402), each with 160 outer updates × 8 training tasks (66,560 examples), four support updates per task (5,120 inner updates + 160 outer updates), 12 support / 40 query examples, and a 16-task inference bank. Conditions: no-adapt, full 9D FOMAML, learned LEO 3→24→9, 3D Mirror, rank-3 additive adapter, native three-angle Givens, and independent least-squares task vectors. The sealed fresh seeds are 44411–44413. `RESULTS_CORE.csv` records actual `.npz` bytes/hashes, examples, update counts, compute proxies and training/adaptation/query time.

## D — Result: FAIL

| Method | 44401 RMSE / bytes | 44402 RMSE / bytes | End-to-end ms (44401 / 44402) |
|---|---:|---:|---:|
| Shared no-adapt | 0.6353 / 737 | 0.8596 / 737 | 0.29 / 0.42 |
| Full FOMAML | 0.4306 / 1,565 | 0.6012 / 1,565 | 25.57 / 6.38 |
| Learned LEO decoder | 0.6243 / 3,468 | 0.8495 / 3,468 | 9.70 / 17.74 |
| Rank-3 additive adapter | 0.5613 / 1,528 | 0.7470 / 1,528 | 6.38 / 8.23 |
| Three-angle Mirror | 0.4086 / 1,206 | 0.6017 / 1,206 | 47.86 / 53.94 |
| Native Givens conditioner | 0.4086 / 1,206 | 0.6017 / 1,206 | 30.64 / 39.53 |
| Independent least squares | 0.0354 / 1,282 | 0.0521 / 1,282 | 2.31 / 1.73 |

Mirror met the relative LEO quality and payload gates: its RMSE was 0.65×/0.71× LEO at 0.35× the LEO bytes. It also beat the rank-3 additive adapter by 27%/19% RMSE while using 21% fewer bytes. But end-to-end adaptation took 4.9×/3.0× LEO time, far above the 1.25× gate. Most decisively, its task codes, actual payload hashes, and query RMSE exactly match the direct native Givens conditioner on both seeds; no Mirror-specific value is established. Independent least-squares fits have 11.5×/11.6× lower RMSE than Mirror, despite using 76 more bytes.

**Fact:** The 1,206-byte Mirror/native payloads and results are byte/hash/function identical in both seeds. Mirror beats the trained LEO and rank-3 controls on quality and bytes, but misses runtime. Payload replay and serialized-byte verification pass. Fresh seeds were not opened.

**Interpretation:** For a task family generated by three rotations, the structured coordinate is more compact and accurate than the underfit learned MLP decoder or rank-3 affine map. It is exactly a native Givens parameterization, so this aligned case is not Mirror-specific. Its eager support adaptation is much slower than LEO, and the independent fit quality indicates large remaining optimization/generalization headroom.

**Hypothesis:** A fixed rotation chart can be a compact decoder prior when the task manifold is actually rotational; this screen does not show general LEO replacement, natural few-shot transfer, or deployment value.

# MA-752 — Factorized control type × injection depth

Status: **FAIL** (scoped synthetic Mirror-specific claim)

## Fact

On 4 held-out condition-depth pairs from a designed 4×4 operator family, independent adapters have zero error at 8,962 B. The factorized condition-code × depth-code representation also has zero error at 6,989 B, a 22.0% reduction that misses the preregistered 25% byte gate. The native factorized control has the same serialized bytes, hash, quality and MAC proxy as Mirror. Additive condition/depth sharing is 7,710 B with held-out nRMSE 0.127; one shared adapter is 989 B with nRMSE 0.221.

## Interpretation

The designed interaction structure can be represented compactly and predicts withheld combinations in this oracle-structured synthetic family. The tested Mirror insertion is exactly ordinary condition/depth factorization and adds no functional freedom over that control. Even with the favorable known-factor construction, the complete payload misses the storage gate. This does not establish learned generalization or diffusion quality.

## Hypothesis result

**FAIL** for Mirror-specific value and the joint storage gate. Fresh/audit was not opened after exact native alias and byte-gate miss.

## Frozen protocol / scope

PA190/PA191 motivate condition-specific ControlNet/T2I-Adapter modules and their injection into a frozen denoiser. This screen isolates control type × injection depth using 4 condition IDs, 4 depth IDs and 12×12 spatial transfer operators. Four combinations are held out. We compare complete NPZ payload bytes, held-out operator nRMSE, MAC proxy and wall time for independent, hard-shared, additive, native factorized and Mirror-factorized state. The factorized family is analytically constructed with known factors; it is not trained from examples.

This is not a pretrained diffusion model, ControlNet checkpoint, T2I-Adapter training, image generation, or aesthetic-quality result. No capacity or deployed latency claim is made.

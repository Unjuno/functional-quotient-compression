# MA-1036 post-audit serialization correction

The first audit opened with preregistered model settings intact, but review of the serialized inference manifest found that it declared four indexes for the shared and unrotated arms even though their payload contains one index reused by four domains. The manifest was corrected to state the physical index count and explicit domain-to-index map. This only fixes inference metadata and its paid byte count; no model, seed, basis, angle, metric, control, or gate changed. The full fresh audit was rerun with the same frozen angles and seeds. Initial opened output is retained as `runs/AUDIT_RESULTS_INITIAL.json`; the corrected rerun is authoritative. Distance-estimator errors were added as a descriptive post-audit replay using these serialized indexes, without changing any decision rule.

A second audit instrumentation review found index-build wall time included rotation matrix construction and counted redundant construction in the shared-basis arm. The runner now constructs a shared basis once and reports only measured FAISS train+add wall for each unique physical index, matching the protocol metric. The complete audit was repeated again with all data and angle settings unchanged. Prior outputs are retained for traceability; only the final replay is authoritative. Short-batch transform+search QPS differed substantially between repeats, so runtime comparison is marked NOT ESTABLISHED rather than selecting a favorable run.

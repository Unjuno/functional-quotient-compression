# MA-425 status: FAIL (extrapolation quality gain; byte gate misses)

## H — falsifiable hypothesis

A continuous depth-time Givens coordinate would extrapolate the rotating vector field to t=2 within 10% of a simple linear time embedding while using <=90% of its actual bytes.

## T — executed

Stable 2D teacher A(t)=Q(0.7t)A0Q(0.7t)^T, trained on derivative samples for t∈[0,1]. Compared constant field, continuous Mirror rotation, linear time embedding A+tB, and four depth-bin matrices clamped to the final bin beyond t=1. Evaluated RK4 at t=1 and t=2 with 16 steps (64 NFE) for every method. 400 AdamW updates × batch 256; 2 development worlds × 3 seeds selected LR 0.01; 3 fresh worlds × 3 seeds. Actual serialized state counted.

## D — FAIL by registered gate

Fresh mean endpoint normalized RMSE at t=2: shared 0.3873; Mirror 0.0171; linear time embedding 0.3133; discrete depth 0.2667. Mirror substantially improves extrapolation quality at the same 1,829B payload as linear time embedding, but fails the required <=90% byte gate. Discrete depth is 1,641B; Mirror is larger, though much more accurate. Solver NFE is identical. Maximum stiffness ratios: Mirror 2.746, linear time embedding 56.347, discrete depth 2.741. Thus Mirror's view avoids the large extrapolation stiffness of the linear embedding, while the strict storage condition remains false.

## C — strongest counter-hypothesis

The teacher is generated by the same continuous rotation family, favoring Mirror. At higher state dimensions, the extra learned base and frequency state may amortize better; this tiny 2x2 system reveals serialized container overhead that erases parameter-count savings.

## U — unresolved

Higher-dimensional/nonlinear fields, adaptive solvers, realistic continuous-depth networks, and actual inference throughput remain untested. This is aligned linear dynamics only.

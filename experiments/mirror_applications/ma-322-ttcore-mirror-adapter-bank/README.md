# MA-322 — TT-core Mirror adapter bank

Status: PROMISING, narrowly for aligned synthetic TT-core views. Prior art: PA36 LoRETTA.

## H

A small Mirror angle may replace per-task TT-core factors when task variation lies on a shared core orbit. LoRETTA independent task factors and generic PCA are mandatory controls.

## T

Synthetic 16×16 TT adapters with four binary modes, rank-2 bonds and 64 tasks. Compare independent full matrices, shared outer TT cores plus independent middle core, Mirror angle over one shared core, and generic rank-2 PCA. Test aligned Givens and independent core strata. Development worlds 32200–32201; fresh 32210–32212; three seeds each. All methods serialize fp16 and are evaluated after deterministic decode.

## D

PROMISING narrowly. Fresh aligned Mirror uses 509 B / NRMSE 5.90e-4 vs LoRETTA-style independent TT cores 2,355 B / 4.05e-4 and generic PCA 625 B / 4.05e-4. Independent cores remain accurate, while Mirror NRMSE is 1.145.

## C

The aligned teacher is generated by the same Givens action; generic PCA may match it. Independent TT cores may be required outside that orbit.

## U

Synthetic matrices only; no LoRETTA training, pretrained model or natural task adaptation.

Development: aligned tasks yield Mirror 509 B / functional NRMSE 6.32e-4, LoRETTA-style independent middle cores 2,355 B / 4.44e-4, and generic PCA 625 B / 4.44e-4. Mirror uses ~78% fewer bytes than the native independent TT-core control and ~19% fewer than PCA, with slightly worse quality and a ~3.8 ms coefficient fit. Independent TT cores remain accurate; Mirror NRMSE is ~1.18. Fresh checks this frontier.

## Fresh result / scope

Fresh aligned tasks reproduce a distinct storage-quality point, with Mirror substantially smaller than LoRETTA-style independent middle cores and slightly smaller than PCA at somewhat higher error. Independent cores remain necessary outside the orbit. This is not evidence about real LoRETTA or language adapters.

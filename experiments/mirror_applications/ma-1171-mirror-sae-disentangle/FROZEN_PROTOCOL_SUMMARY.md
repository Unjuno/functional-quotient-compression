# MA-1171 frozen preregistration — synthetic SAE feature separation

**Frozen 2026-10-20 before any training**. Full local PROTOCOL.json SHA256: `27f914fe06676bf46b8a786667df644859da3a48e0c707b172514d8ca39fee1a`.

This is **not audio**. Test an unsupervised sparse autoencoder on synthetic mixed model activations with known (evaluator-only) features.

- 32-dimensional activations = exactly 3 nonnegative ground-truth features sampled from 64 unit decoder atoms + N(0,.01) noise. No true features or factor weights accessible to trainer. Two teacher distributions: (i) uniform independent features, (ii) 75% anchor-neighbor cooccurring pairs. Fresh OOD breaks pair dependence; in-distribution fresh is separately held out. Independent train/dev/fresh RNG with seeds [11,23,47] and fixed world/seed/split sources. Train N8192, dev N1024, fresh ID N2048, fresh OOD N2048.
- Five models: `dense_onepass`, `dense_loop`, `lowrank_loop` (rank 8), `affine_loop`, `mirror_loop`. All have a learned independent 64×32 SAE reconstruction dictionary. In the latter two, 64 logical encoder weight vectors are generated from 32 shared physical core coefficients, 8 deterministic signed-permutation pages, 64×6 learned address coordinates and per-row gains. Mirror alone adds the orthogonal Householder → tanh → inverse-Householder weight transformation; affine uses *identical* pages, addresses, gains and loops as its control. Loop unroll count T3 uses sparse residual feedback, all models use TopK3. Do not claim total decoder compression.
- CPU FP32 one thread, AdamW lr .003 weight_decay 1e-5, 500 optimizer updates, batch160, dev every100 steps; best dev normalized MSE chosen. No fresh tuning. Also record exact learned parameter counts / model serialization bytes and B=1/B=128 median isolated CPU latency (100 measured runs, 15 warmups).
- One-to-one evaluator-only Hungarian matching maximizes **signed positive decoder direction cosine** to planted ground-truth factor dictionary. Report matched support micro-F1 on fresh ID and fresh OOD, unique cosine recovery, reconstruction NMSE, and average actual L0. Ground-truth factor identities are never shown to SAE training. This synthetic matching does not establish real-world mechanistic interpretability.
- Primary stringent PASS: Mirror OOD support-F1 improves by >=.05 absolute over both same-address affine_loop and dense_loop in >=5/6 world-seed pairs, and its fresh ID NMSE is <=1.10x affine in every pair. If simpler affine wins, report no Mirror-specific benefit. This is a tiny synthetic screening, not capacity or general language-model evidence. No merge to main.

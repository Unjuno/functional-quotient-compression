# MA-437 — Mirror views in native S4 structured dynamics

Status: SCREENING  
Evidence lane: MECHANISM / STORAGE / COMPUTE  
Base commit: `95d9ae2dde5aa4e323e0e0bf6872824354497bad`

## H — falsifiable hypothesis

For long sequence regression generated by stable S4-style normal-plus-low-rank transitions, a shared structured transition plus per-role low-description Mirror coordinates can match independent structured transitions at lower serialized payload bytes while maintaining stability.

## T — protocol

This is a small state-space mechanism screen, not an S4 language-model benchmark. The transition is parameterized in the S4D- real diagonal-plus-low-rank spirit: a stable negative diagonal plus a rank-one correction. The Mirror variant applies role-specific 2D Givens conjugations to the shared low-rank factor subspace; it does not materialize dense role matrices. Compare shared S4 parameters, a simple per-role scalar/diagonal gate, a tied structured transition plus Mirror, an equal-budget low-rank residual control, and independent structured transitions. Evaluate autoregressive state trajectories at trained and extrapolation lengths, stability, actual serialized inference bytes, transition MAC proxy, and CPU rollout wall time.

## Mirror insertion

> **Mirror insertion:** this experiment adds a per-role coordinate `m` to S4's rank-one structured correction so that distinct long-range dynamics can be expressed without storing a complete structured transition per role.

- Native method: stable diagonal-plus-low-rank SSM dynamics.
- Mirror coordinate: one angle per role rotating the shared rank-one correction factors in a 2D latent plane.
- Persistent `m`: learned/stored per logical role.
- Cheapest competing freedom: per-role scalar diagonal gate and rank-one residual.

## Prior-art delta

PA74 establishes S4's normal-plus-low-rank structured transition and efficient recurrent/convolutional forms. MA-434 tested views in selective Mamba-style dynamics. Here we isolate Mirror in native structured factors and explicitly audit stability. The teacher is aligned to the specified structured-factor View, so evidence is mechanism-only.

## Controls

Shared structured SSM; role scalar/diagonal gate; tied S4 plus Mirror coordinates; equal-budget rank-one residual; independent structured SSM upper control.

## Gates

- PASS: on each fresh world, Mirror trajectory NRMSE <= 1.10x independent and <= 60% of independent actual bytes; no unstable poles; no more than 1.25x independent recurrent MACs.
- FAIL: quality or byte gate missed, any unstable transition, or the simple gate/residual control matches Mirror at lower bytes.
- NOT ESTABLISHED: implementation or split-integrity error prevents comparison.

## C — strongest counter-hypothesis

S4's low-rank factors may not be closed under the chosen rotations, so the Mirror code may need factor growth or private residuals; simple role gates may capture the teacher at lower bytes. A deliberately aligned teacher will overstate natural S4 transfer.

## U — boundaries

Small state dimension and synthetic aligned dynamics only. No FFT kernel, long-range language benchmark, GPU efficiency, or learned routing evidence.

# MA-350 — Multimodal Mirror posterior codebook

Status: SCREENING. Prior art: PA41 Rank-1 BNN mixture.

## H

For a synthetic posterior predictive mixture of K distinct logistic functions lying on one known rotation orbit, a shared base vector plus one phase per mode may reproduce NLL/diversity with fewer bytes than direct two-coefficient or independent-vector mode storage. This is an oracle representability/storage screen, not learned posterior capacity.

## Mirror insertion

> **Mirror insertion:** this experiment adds a per-mode phase `m_k` to one shared 16-dimensional logistic weight vector, encoding K functionally distinct posterior modes without storing K full vectors.

Compare phase codebook, direct two-coefficient codebook, and independent mode vectors. All methods store the same uniform mode probabilities. Measure posterior mixture NLL/Brier/ECE, pairwise member disagreement, actual payload bytes and mixture evaluation time.

## T

A K=32 component binary logistic mixture. Mode weights are generated by rotating the first two coordinates of a shared 16-dimensional vector through evenly spaced phases; remaining coordinates are shared. Labels are sampled from the equal-weight predictive mixture. Development worlds 35021–35022 and fresh worlds 35031–35033, with IID and shifted-input test sets. No training; modes are oracle-provided and held-out labels are used only for evaluation.

## Gates

**PROMISING:** Mirror mixture NLL within .01 of the exact independent mixture, pairwise disagreement retained within .02, and payload <=.80x direct coefficient codebook. **FAIL:** Mirror does not retain quality/diversity or misses the byte margin. These tests do not count K as independent capacity.

## C / U

Teacher modes are constructed on the same rotation orbit as Mirror. No posterior fitting, natural task data, mode discovery, calibration shift robustness or downstream utility is established.


## Results

**H:** a phase codebook can represent a K=32 posterior predictive mixture of distinct functions more compactly than direct coefficients or independent models while preserving mixture quality and mode diversity.

**T:** three fresh worlds, K=32 equally weighted logistic modes on a planted rotation orbit; 4,096 IID and 4,096 shifted OOD labels/world. Modes are oracle-specified; no optimization or posterior inference was performed.

**D — PROMISING, narrowly:** Mirror payload 429 B vs direct coefficients 564 B (24.0% fewer) and independent mode vectors 2,357 B (81.8% fewer). IID NLL .47842, OOD NLL .49346; both direct and independent controls match these metrics exactly. Pairwise disagreement is .05674 IID/.07267 OOD for all 32-mode controls, while single shared model has zero disagreement and worse NLL (.53413/.60112). ECE is .01594 IID/.01247 OOD. Actual serialization includes shared base, all mode coordinates, uniform mixing weights and metadata.

**C:** the task modes are planted on the same orbit as Mirror and supplied by an oracle. The generic direct codebook is functionally identical; the byte saving comes from representing the circular constraint with one scalar rather than two values per mode.

**U:** learning the modes, natural multimodal posterior fit, downstream task utility, nonuniform mixture weights and runtime-efficient kernels are untested. K counts measured functions in this synthetic evaluation, not independent model capacity.

### Fact / interpretation / hypothesis

**Fact:** 24 fresh rows across three worlds × four methods × two splits; payload bytes/hash and metrics replay exactly; two tests pass.

**Interpretation:** a structured phase can improve the storage frontier for an already-known aligned multimodal family, while generic coefficient coding retains identical function quality at higher bytes.

**Hypothesis:** learned posteriors may benefit when mode angles occupy a compact shared orbit, but mode discovery and natural data are still needed.

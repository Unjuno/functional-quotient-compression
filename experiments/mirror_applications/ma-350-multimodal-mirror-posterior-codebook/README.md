# MA-350 — Multimodal Mirror posterior codebook

Status: SCREENING. Prior art: PA41 Rank-1 BNN mixture.

## H

For a synthetic posterior predictive mixture of K distinct logistic functions lying on one known rotation orbit, a shared base vector plus one phase per mode may reproduce NLL/diversity with fewer bytes than direct two-coefficient or independent-vector mode storage. This is an oracle representability/storage screen, not learned posterior capacity.

## Mirror insertion

> **Mirror insertion:** this experiment adds a per-mode phase `m_k` to one shared 16-dimensional logistic weight vector, encoding K functionally distinct posterior modes without storing K full vectors.

Compare phase codebook, direct two-coefficient codebook, and independent mode vectors. All methods store the same uniform mode probabilities. Measure posterior mixture NLL/Brier/ECE, pairwise member disagreement, actual payload bytes and mixture evaluation time.

## T

A K=32 component binary logistic mixture. Mode weights are generated by rotating the first two coordinates of a shared 16-dimensional vector through evenly spaced phases; remaining coordinates are shared. Labels are sampled from the equal-weight predictive mixture. Development worlds 35021–35022 and fresh worlds 35031–35033, with IID and shifted-input test sets. No training; modes are oracle-provided and held-out labels are used only for evaluation.

## Gates

**PROMISING:** Mirror mixture NLL within .01 of the exact independent mixture, pairwise disagreement retained within .02, and payload <=.80x direct coefficient codebook. **FAIL:** Mirror does not retain quality/diversity or misses the byte margin. These tests do not count K as independent capacity.

## C / U

Teacher modes are constructed on the same rotation orbit as Mirror. No posterior fitting, natural task data, mode discovery, calibration shift robustness or downstream utility is established.

# MA-1016 — TensorHyper-VQC task code sharing

Status: SCREENING
Evidence lane: MECHANISM / STORAGE / COMPUTE
Base commit: `83f8a136c` (MA-1014 evidence branch)
Prior art: PA309, with PA308/PA311 context

## Hypothesis

H: For a deliberately aligned family of task-specific VQC angles generated by one Tensor-Train (TT) circuit hypernetwork, representing each task latent as a one-scalar Givens phase can preserve shot-based classification while using fewer actual inference bytes than a rank-2 native TT task core.

## Mirror insertion

> **Mirror insertion:** this experiment adds task phase `m_t` to the first latent core of a shared TT VQC generator so that multiple logical task circuits can be selected without storing a separate rank-2 task vector or a full gate-angle vector for each task.

- Shared physical object: the TT cores mapping task latent → layer × qubit × rotation angles.
- View: task-specific angle `m_t`, decoded as `(cos(m_t), sin(m_t))`.
- Logical functions: four task-conditioned circuits on the same 4-qubit, 2-layer gate skeleton.
- Simplest native control: the same scalar phase stored as an ordinary polar coordinate, which is expected to be functionally identical.
- Closest prior art: PA309 uses a classical TT hypernetwork to generate circuit parameters. This is a bounded TT-inspired statevector screen, not an official TensorHyper-VQC reproduction or QPU result.

## Protocol

`PROTOCOL.json` was frozen before execution and amended after the initial development teacher collapsed all tasks to one label function. Amendment 01 selects a teacher with four distinct task functions using development-only task diversity, then fixes a common compact inference serializer. The independent angle bank, full native TT task cores, Mirror phases, and ordinary scalar-phase control produce the same intended task circuits. A deterministic 4-qubit statevector simulator computes expectations, then a seeded 1,024-shot readout estimates accuracy. No parameter optimization or fresh/audit data is used.

## Gates

- **PASS (aligned mechanism only):** Mirror retains ≥98% of teacher task accuracy across all four tasks, uses at least 10% fewer actual bytes than native TT task cores, and beats the ordinary scalar-phase control by ≥2 percentage points at equal shot/gate budgets.
- **FAIL:** Mirror exactly aliases or loses to the ordinary scalar-phase control, or misses the quality/bytes gate against native TT.
- **NOT ESTABLISHED:** statevector replay, serialization, or shot-accounting checks fail.

No quantum hardware advantage, noisy-device robustness, or natural task-family capacity claim is permitted from this synthetic screen.

# MA-251 — factorized expert x depth Mirror coordinate

Status: **PROMISING (factorized linear role-depth mechanism)**  
Evidence lane: MECHANISM / STORAGE / RUNTIME  
Base commit: `809f9d50ef85d470d8bac045db291349e264dcba`

## H — falsifiable hypothesis

Factorized expert and depth Mirror coordinates can express a Cartesian family of logical role-depth functions from one shared expert matrix with fewer actual bytes than a per-pair coordinate table, when roles factor across expert and depth. Independent pair functions should expose the need for private/table parameters.

## T — execution

PA01 motivates expert tying across depth; PA06 motivates static per-depth modulation controls. The experiment used 4 expert identities x 4 depth positions, 16D inputs and 12D outputs. In the aligned teacher, expert Givens rotations act on the first hidden half and depth rotations on the second half before a single shared matrix. In the independent-pair teacher, each of the 16 pairs has an unrelated matrix.

Controls were 16 untied matrices, hard tying, expert-only tying, expert tying plus static per-depth rank-1 LoRA, depth tying, expert-only views, depth-only views, factorized Mirror, and a Cartesian per-pair Mirror angle table. All methods used matched minibatches, 1,200 AdamW updates, batch 64, and common LR 0.01 selected on development world 25100. Fresh worlds were 25101–25103. The 4x4 combination count is not treated as independent capacity.

## D — PROMISING on factorized roles; independent pair functions require more capacity

### Factorized-axis teacher

| Fresh world | Untied MSE | Factorized Mirror MSE | Cartesian Mirror MSE |
|---|---:|---:|---:|
| 25101 | 5.42e-9 | 9.76e-10 | 9.17e-10 |
| 25102 | 7.00e-9 | 1.08e-9 | 1.19e-9 |
| 25103 | 8.63e-9 | 1.21e-9 | 1.37e-9 |

Factorized Mirror passed the registered quality gate in all three worlds. It used 3,608 B vs 3,803 B for the Cartesian angle table (-5.1%) and 15,317 B for untied matrices (-76.4%). Hard tying had MSE 0.44–0.48. Expert/depth one-axis views had MSE 0.16–0.32; expert tying plus static depth rank-1 LoRA had MSE 0.15–0.29. Factorized coordinates recovered the combined role-depth behavior that neither single-axis view or static adapter recovered here.

### Independent pair matrices

Untied controls fit at MSE <1.3e-8. Factorized Mirror had MSE 4.93–5.29; the larger Cartesian coordinate table improved this to 4.48–4.66 but remained far from the upper control. Expert tying plus static depth rank-1 LoRA gave 4.13–4.28. This maps a clear boundary: the 4x4 combinations generated by factorized coordinates do not act like 16 independent functions when the teacher's pair matrices are unrelated.

### Storage / compute / runtime

Actual payloads: factorized Mirror 3,608 B; Cartesian Mirror 3,803 B; untied 15,317 B; hard tied 3,027 B; expert-tied 5,530 B; expert-tied + depth LoRA 6,365 B; depth-tied 5,529 B. All matrices, coordinates, adapters and metadata are included.

Aligned active-compute proxy was 73.7M factorized vs 103.2M Cartesian and 707.8M untied. Median training wall times were 1.89 s, 1.21 s and 1.30 s, respectively. Median CPU throughput was 0.667M examples/s factorized, 1.05M Cartesian, and 1.55M untied. The eager factorized implementation has an inference slowdown despite lower proxy; optimized kernels are untested.

## C — strongest counter-hypothesis

The aligned teacher was intentionally constructed from exactly the two disjoint Givens factors implemented by the student. The result demonstrates recovery and compression for this separable function family; it does not establish a gain on real experts or generally compositional tasks. The runtime difference may reflect implementation overhead rather than necessary compute.

## U — not established

Nonlinear experts, router/load balance, natural language, longer depth, arbitrary interactions between expert and depth, near-convergence fixed-byte capacity, and optimized kernels remain untested. Independent-mode errors do not specify the minimum private rank or number of residual matrices required.

## Fact / interpretation / hypothesis

- **Fact:** Factorized Mirror matched the untied upper control in 3/3 aligned fresh worlds, with 3,608B payload. Independent pairs caused large errors for both factorized and Cartesian coordinates; full untied experts remained accurate.
- **Interpretation:** Separate expert and depth codes can reproduce all 16 combinations without a Cartesian parameter table when target transformations factor across the axes. This does not multiply independent capacity by 16.
- **Hypothesis:** A small private residual on top of the factorized coordinate may recover some nonseparable expert-depth interactions; this needs a separate preregistered experiment.

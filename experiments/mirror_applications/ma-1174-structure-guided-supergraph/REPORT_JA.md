# MA-1174 — Mirrorスーパーグラフの「学習誘導型」経路切断：検証報告

**2026-10-21 JST / 合成関数回帰の66モデル実験 / 判定：機構PASS、軌道改善FAIL、Mirror固有品質FAIL。**

## 研究対象と事前登録

構造の即時重要度ではなく、**切断した後に共有物理核がより良い関数を学習するか**が主眼。`PROTOCOL.json` SHA256 `80308193fd6b22aabe84f6e27c9f8350dafd792b433d35b01f7cff357d5207e8`を訓練前に固定。2教師分布×3 seeds (1301/1307/1319)×11条件=**66モデル**。学習データ1024、dev384、fresh768、OOD768。AdamW 260実更新、バッチ64、LR0.007、重み減衰1e-5、FP32 CPU 1スレッド。固定試行探索を用いる場合は2回の介入ごとに5候補×6更新で計60の複製Optimizer更新を追加し計上。既存の学習済みLMや自然文章ではない。

- 4ノード、全有向接続×2ビュー＝32仮想エッジ、2回Loop。1つの**128係数**の共有物理核、32×4アドレス、32ゲート、4×8ノードバイアス＝**320個の独立学習係数**。32×128=4096仮想重み値は独立の4096自由度ではない。
- Mirrorは符号付置換された4ページをsoftmaxアドレスで混ぜ、固定Householder→tanh→逆Householderで仮想重みを生成。対照の直接tanhとaffineは**同じアドレス／ゲート／候補介入**を共有。
- 教師A：8エッジだけ有効なMirrorグラフでラベル生成。教師B：独立通常MLP。教師の係数と有効エッジは学習に使用せず、正解Oracle複製は別の事後機構チェックのみ。各split独立乱数。train-only target RMSをNMSEの分母に固定。
- 経路介入t=90,170で各4エッジをOFFにする。勾配符号衝突の大きい4本・最小ゲート4本・最小一次Taylor4本・ランダム4本を候補に、**全員共通の未来trainバッチ6更新**を同じOptimizer状態から分岐試行。dev損失に基づき候補を選択。guardedは維持の将来dev予測より少なくとも0.0005改善する場合のみ切断。
- 最終同一24エッジを**初期状態から260更新**学習する `mirror_from_start_same_mask` を追加。候補選択にfreshは一度も使わない。

## 事前登録された合否

- **H_learning：FAIL (0/6)**。将来評価型切断が、ランダム・小ゲート・同じ最終マスクを最初から学習、の3対照に対してすべて5%以上改善したペアは**0/6**。同じ最終マスクで最初から学習したモデルには**0/6勝**で、paired比中央値 lookahead/from-start=**1.05084**（大きいほどLookaheadが不利）。
- **H_Mirror-specific：FAIL (1/6)**。直接tanhとaffineの両方へ5%以上勝ったペアは**1/6**。直接tanhはHouseholderなしで同じ仕組みの一部を実装できる。
- **Mechanism：PASS (6/6)**。経路切断直前／直後に**同一trainバッチで共有核勾配方向が5°以上変化**。各ペア2介入とも最大21°以上。変化の存在は測れたが、それが汎化改善につながるとは限らない。
- **Aligned oracle representability：PASS**。同一教師パラメータ＋有効エッジを事後コピーすると出力の最大絶対誤差は3 seedすべて0.0（学習が正解を発見できたという意味ではない）。
- **Guarded：12/12介入見送り**（6ペア×2）。短い将来dev試行では、切断に肯定的な証拠が得られなかった。

## 失敗要因の候補と次の判別

1. **試行6更新が短い：** 即時損失は切断のたび通常悪化しており、候補同士の未来評価順位は長期の良さを予測できていない可能性。異なるHを事前登録して検証する必要がある。
2. **共有表現の学習が弱い：** 最強の通常MLPはFresh NMSE約0.02145、Mirrorは約0.13491。Mirror関数の学習能力やアドレスの最適化が不十分であり、構造選択だけ変えても追いつかない可能性。
3. **ガードが全拒否：** モデル内で刈り取りにより将来改善する明瞭な局面を作れていない。共有勾配角の変化は起きても、**良い方向**である保証はない。
4. **構造の強すぎる共有と教師バイアス：** Mirror教師は有利でも元々nativeとの差が大きい。ノード・Mirror方向・反復数を最適化したわけではなく、このFAILは最終構想全体の否定ではない。
5. **探索計算コスト：** lookaheadの試行更新60回を計上すると切断の下限学習MACは保持方式より多い。同じ予算を素直に追加学習した対照が良い。

**次の候補は全構造の拡張ではなく、学習が改善される介入を因果的に識別できる人工二課題共有核と、切断後の適応期間（H）に対するプローブ順位相関を切り分けること。** これは未来の研究案であり今回の凍結結果への事後チューニングではない。

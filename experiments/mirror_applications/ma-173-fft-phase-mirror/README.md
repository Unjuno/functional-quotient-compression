# MA-173 — FFT phase Mirror

## Prior-art search

The targeted search surfaced qFHRR (arXiv:2604.25939), which encodes HRR/FHRR phases with quantized phase and integer arithmetic. It is directly relevant to phase representation and arithmetic cost, but does not test many role-specific neural functions sharing one learned weight matrix. Clifford-VAE (arXiv:2609.28409) learns HRR-compatible unitary embeddings and reports improved VSA binding/unbinding tests; it learns input representations, not role views over shared model parameters. PA11 requires MAP/sign-permute and Hadamard controls; PA12 establishes circular convolution as an established binding operation. MA-171 tested fixed HRR addresses against an HRR-aligned teacher. MA-173 isolates the extra freedom of learned per-role Fourier phases.

## H — falsifiable hypothesis

Learned Fourier phase coordinates can make one shared matrix behave as four logical functions when teacher roles lie in the same real unitary phase orbit. The method should match untied held-out MSE within 1.10× while using at most 0.65× its actual serialized bytes. Fixed HRR, MAP/sign-permute, Hadamard, Givens, tying, scalar gate, private rank-1, and untied matrices are controls.

## T — protocol

Each role maps 16 input dimensions to 12 outputs. The aligned teacher applies a role-specific real orthogonal circulant transform generated by seven interior rFFT phase coordinates; DC and Nyquist phases are zero. The learner begins from zero phases and trains its shared matrix and phase addresses. Teacher and fixed-control address seeds differ. The independent condition samples unrelated role matrices.

Development compares learning rates 0.003 and 0.01 on seeds 17301 and 17302, with one common rate selected by mean held-out MSE across all methods and both conditions. If the development gate passes, fresh seeds are 17311–17313 at the frozen rate. Training uses 1,200 AdamW updates, batch 64, matched batches, and one CPU thread. Metrics include held-out MSE/R², actual serialized bytes, examples/updates, approximate active MACs, wall time, and inference throughput. This is fixed-budget synthetic evidence, not an LM or capacity claim.

## D — PROMISING on a narrowly aligned synthetic screen

### Fact

- Development selected common learning rate 0.01 by the preregistered aggregate mean-MSE metric: 3.2991247 versus 3.2991971 at 0.003. Both development worlds passed the aligned quality and byte checks before fresh access.
- On fresh aligned seeds 17311–17313, learned FFT-phase MSE was **1.053e-9, 1.207e-9, 1.190e-9**; untied MSE was 2.569e-9, 3.110e-9, 2.361e-9. Learned phase passed the <=1.10x untied MSE gate in 3/3 worlds.
- Actual serialized learned-phase payload was **3,169 bytes**, versus **5,349 bytes** untied (0.592x; 40.8% fewer). The byte count includes learned phase coordinates, shared weights and configuration. Fixed HRR/MAP/Hadamard used 2,853B but had large aligned MSE; Givens used 3,233B and also had large MSE. Rank-1 residual used 3,741B and remained far from teacher quality.
- Learned FFT phase used 103.22M active MAC proxy versus 176.95M untied (0.583x), but mean training wall was 0.980s vs 0.784s, and median CPU inference throughput was 1.42M vs 1.68M examples/s. Thus this screen shows a storage/quality/operation-count tradeoff, with a measured wall-time regression.
- On unrelated independent role matrices, learned FFT-phase MSE averaged 3.57 while untied averaged 2.65e-9. Private full matrices remained necessary.
- All methods used 1,200 optimizer updates and 76,800 training examples per model. No near-convergence or fixed-byte capacity comparison was run.

### Interpretation

Learned real Fourier phases can serve as compact coordinates for role functions when the teacher is generated from the same phase family. The learned address beats fixed HRR, MAP, Hadamard and Givens controls on this teacher, whereas MA-171's fixed HRR address worked on its HRR-generated teacher. The results map which address family fits the task structure; they do not establish general superiority of FFT phase or more capacity.

### Hypothesis

The per-role phase coordinates likely capture the specific circulant transform while the shared matrix captures common content. Arbitrary unrelated functions do not share the required phase orbit and need private parameters.

### C — strongest counter-hypothesis

The teacher and learned address use the same transform family, making this an intentionally favorable reconstruction problem. Untied fits were also trained for only 1,200 updates. The quality difference may be due to learning efficiency and teacher alignment; an untied model at convergence should reproduce all roles.

### U — not established

Learned phase behavior on real neural layers, quantized phase code payloads, larger dimensions, calibrated activations, nonlinear experts, natural-language quality, optimized FFT kernels, convergence-matched controls, and fixed-byte frontiers remain untested. The current CPU implementation has lower active MAC proxy but slower wall time and inference throughput.

### Fact / interpretation / hypothesis

- **Fact:** learned phase passed its preregistered fixed-update quality/byte gate in 3/3 fresh aligned worlds; it failed badly on unrelated roles and measured runtime was slower than untied.
- **Interpretation:** the physical-to-logical compression works within a matching Fourier-phase orbit, while unrelated roles require private capacity.
- **Hypothesis:** imperfect alignment and convergence-matched controls will reduce the apparent quality advantage; learned phase may remain useful where actual stored weights dominate runtime.

## Verification

Three tests cover all-method payload restoration, real orthogonal phase views, and reconstruction of the aligned teacher from the shared matrix and its learned phase coordinates. The 72-row development grid and 90 core rows were replayed as 126 distinct training runs; serialized bytes and compute matched exactly, maximum MSE difference was 4.92e-10 and maximum R² difference was 5.00e-9.

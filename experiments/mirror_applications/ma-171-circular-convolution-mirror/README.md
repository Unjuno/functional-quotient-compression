# MA-171 — circular convolution Mirror

## Prior-art search

The targeted search reaffirmed that HRR is an established circular-convolution binding family (Plate, 1995; PA12), not a novel operator. Carzaniga et al. (2025; PA11) compare MAP, Hadamard linear binding, and HRR in deep-learning-inspired environments; the repository's MA-250 experiment also implemented all three as fixed expert addresses and found them poor against a Givens-aligned teacher. The present experiment flips the alignment question: does an HRR address recover functions when the teacher itself is generated by HRR?

Two recent papers broaden the comparison. Clifford-VAE (arXiv:2609.28409) learns data embeddings constrained to HRR-compatible unitary representations and reports better VSA binding/unbinding measures than Gaussian or hyperspherical VAE representations; it learns perceptual embeddings, not shared neural weight views. qFHRR (arXiv:2604.25939) targets quantized phase representations and integer arithmetic; it studies representation and arithmetic efficiency, not parameter sharing across neural functions. Their existence cautions against calling circular convolution a new binding mechanism or conflating learned code quality with shared-weight capacity.

## H — falsifiable hypothesis

When a four-role teacher is generated by unit-spectrum circular-convolution views of one shared linear expert, the fixed HRR address should recover role outputs within 1.10× untied held-out MSE using no more than 0.65× the untied actual serialized bytes. MAP/sign-permute and Hadamard binding, hard tying, Givens views, and a rank-1 private residual are required controls.

## T — protocol

Four roles map 16-dimensional inputs to 12-dimensional outputs. In the aligned condition, a shared expert is transformed by four deterministic real orthogonal circulant matrices with unit-magnitude spectrum. The per-world address seed is charged and reproduced from metadata. In the independent condition, every role receives an unrelated matrix. Methods are untied, tied, scalar gate, rank-1 residual, MAP, Hadamard, HRR, and learned Givens views. All use 1,200 AdamW updates, batch size 64, matched minibatches, and one CPU thread. Development seeds are 17101/17102; fresh seeds are 17111–17113, opened only if development passes. Two learning rates are compared on development and one common rate is frozen.

Metrics are held-out MSE and R², actual serialized model bytes, training examples/updates, approximate active MACs, training wall time, and CPU inference examples/s. Actual payloads are `torch.save` state dictionaries plus the serialized configuration and address seed. This is a synthetic aligned-mechanism screen, not an LM result.

## D — PROMISING, with protocol amendment disclosed

### Fact

- Development selected common learning rate 0.003 from the registered aggregate metric (mean held-out MSE over all methods and both conditions): 3.19288 at 0.003 versus 3.19729 at 0.01. This selection file was written before any fresh access.
- On corrected amendment A1 fresh seeds 17121–17123, HRR MSE was **9.21e-5, 1.78e-4, 7.83e-5**, versus untied MSE 2.60e-3, 8.39e-4, 1.24e-3. HRR beat the untied fixed-update MSE in 3/3 worlds; the mean ratio was 0.0745. It also beat residual-free tying, scalar gate, rank-1, MAP/sign-permute, Hadamard and Givens on the deliberately HRR-aligned teacher.
- HRR payload was **2,853 bytes** versus 5,349 bytes untied (0.533×, 46.7% fewer). Each model ran 1,200 updates on 76,800 examples. HRR active MAC proxy was 58.98M versus 176.95M untied. Median measured training wall was 0.557 s versus 0.757 s; median one-thread inference was 1.52M versus 1.45M examples/s in this small CPU harness.
- On arbitrary independent role matrices, HRR averaged MSE 4.31 versus untied 0.00111; it did not replace private functions.
- **Process deviation:** the original fresh seeds 17111–17113 were mistakenly launched at learning rate 0.01 after development had selected 0.003. Their 48 rows are preserved in `RESULTS_EXPLORATORY.csv` and excluded from the decision. Amendment A1 fixed the already selected 0.003 and new seeds 17121–17123 before those corrected fresh results were opened. No hyperparameter was selected from either fresh run.

### Interpretation

This demonstrates a narrow storage and fixed-budget learning-efficiency effect when the teacher's functions are created by the same HRR address family. It does not establish added capacity: the address family was built into the teacher, the comparison used 1,200 updates rather than near-convergence, and untied weights can represent the functions independently. MA-250's complementary Givens-aligned test found the fixed VSA operators poor, confirming that alignment determines which address family works. Arbitrary role functions require private weights.

### Hypothesis

HRR's charged role codes are acting as a compact shared coordinate for this teacher, while unrelated functions have no shared circular-convolution structure. The large independent-mode gap supports the boundary hypothesis that private state is required when the role matrices do not share an address orbit.

### C — strongest counter-hypothesis

The result follows by construction because teacher and HRR use the same seeded transform. The fixed update budget may also explain why the shared model beats the untied model on MSE; a converged untied control should reach the exact teacher. Therefore the evidence supports storage/learning efficiency within a known shared family, not capacity growth or general HRR superiority.

### U — not established

Near-convergence or fixed-byte frontier, learned/optimized address codes, imperfect or unknown teacher coordinates, nonlinear MoE, natural-language quality, quantized payloads, larger shapes, and whether the same gain survives calibrated activations and optimized kernels remain untested.

### Fact / interpretation / hypothesis

- **Fact:** in 3/3 corrected fresh aligned worlds, HRR achieved lower fixed-update MSE than untied with 46.7% fewer serialized bytes. In unrelated worlds it failed badly.
- **Interpretation:** circular-convolution coordinates are effective for functions generated by the same HRR orbit; address families are not interchangeable.
- **Hypothesis:** the compression/quality effect will shrink when teacher alignment is imperfect or when untied controls are trained to convergence.

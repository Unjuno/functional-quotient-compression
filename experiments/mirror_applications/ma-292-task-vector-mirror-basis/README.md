# MA-292 — Task-vector Mirror basis

## H — Hypothesis

A shared basis with compact View coordinates can reconstruct and compose multiple task deltas with fewer bytes and less interference than raw vectors, beyond PCA/SVD and ordinary coefficient controls.

## T — Planned experiment

Sixteen synthetic task vectors, whole-task held-out identities and held-out compositions. Compare raw vectors, PCA basis, Mirror/generic coefficients, ordinary addition and independent composition upper. Fresh worlds 29210–29212 × seeds 0–2 remain locked.

## D — Pending

## C — Strongest counter-hypothesis

Task arithmetic or a generic PCA/SVD basis may achieve the same composition with no Mirror-specific function. Random task vectors may not support meaningful composition.

## U — Unknown

Held-out task recovery, composition quality, interference, bytes and fit compute.

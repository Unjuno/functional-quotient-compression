# MA-770 — Cross-domain functional-coordinate frontier map

Status: **NOT ESTABLISHED** (selected report meta-analysis; no universal Mirror claim)

## Fact

The selected 16 completed screens span neural operators, relational GNNs, diffusion controls, goal-conditioned local rules, cellular-rule banks, morphology recovery and online adaptation. Reported byte savings against each screen's named comparison range from **−21.5%** to **98.3%**. Compute ranges from lower MAC/adaptation work in some shared bridges to **3×** MAC for rule-basis views; some view-based inference can be precomposed to change that tradeoff. Every included screen reports an exact ordinary native control alias or a simpler control that meets the quality gate. Quality units differ by task and were not pooled.

## Interpretation

There are useful storage and adaptation signals in selected aligned synthetic families, but this pilot cannot establish universality. Compression, quality, compute, adaptation, and the definition of an independent logical function differ across domains. A single scalar rank would hide important failures and tradeoffs, so the map preserves each source experiment's native metric and control.

## Hypothesis result

**NOT ESTABLISHED** for cross-domain universality. This is a selected evidence reconciliation, not a fresh benchmark or the full registry map. The per-domain rows are descriptive and should not be ranked against one another.

## H / T / D / C / U

- **H:** Functional-coordinate utility may transfer across unrelated physical-sharing domains under equalized byte and quality frontiers.
- **T:** 16 completed synthetic/mechanism screens from MA-733–767 were reconciled using their own final reports and actual serialized-byte values; the selection and row-level normalized savings are reproducible from the included script.
- **D:** **NOT ESTABLISHED.** Descriptive within-domain signals exist, but this selected, heterogeneous set supports no aggregate or universal claim.
- **C:** Most positive compression is explained by familiar native bases, ordinary coordinates, low-rank adapters, hypernetworks or analytic generators; several byte/compute gates also fail.
- **U:** Full candidate registry, matched cross-domain code budgets, natural/pretrained tasks, comparable quality targets, fresh audits and deployed hardware.

# MA-271 — OFT versus Mirror task views

## H — Hypothesis

A one-angle orthogonal View can represent aligned task transforms over a shared frozen function with less task state than independent OFT matrices. Independent rotations test where private transform parameters become necessary.

## T — Planned experiment

Frozen 16→32→8 feature network; eight tasks; aligned one-plane rotations and independent orthogonal maps; 128 support and 512 audit samples per task. Compare no view, support-fitted independent OFT, oracle-projected independent OFT upper control, fixed-plane Mirror and the generic scalar control. During development, support-only Cayley fitting retained NRMSE≈0.23 after 2000 updates on an independent map; therefore independent OFT fitting is not an adequate capacity control there. This amendment was made before fresh access. Fresh worlds 27110–27112 × seeds 0–2 remain locked until amended source/protocol are frozen.

## C — Strongest counter-hypothesis

An aligned one-plane teacher makes the Mirror coordinate a matched parameterization; OFT already provides orthogonal adaptation and a fixed-plane scalar control may reproduce any apparent Mirror gain.

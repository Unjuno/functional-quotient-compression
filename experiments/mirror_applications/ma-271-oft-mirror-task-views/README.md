# MA-271 — OFT versus Mirror task views

## H — Hypothesis

A one-angle orthogonal View can represent aligned task transforms over a shared frozen function with less task state than independent OFT matrices. Independent rotations test where private transform parameters become necessary.

## T — Planned experiment

Frozen 16→32→8 feature network; eight tasks; aligned one-plane rotations and independent orthogonal maps; 128 support and 512 audit samples per task. Compare no view, independent OFT, fixed-plane Mirror, shared random-plane control and dense upper control. Fresh worlds 27110–27112 × seeds 0–2 remain locked until source/protocol are frozen.

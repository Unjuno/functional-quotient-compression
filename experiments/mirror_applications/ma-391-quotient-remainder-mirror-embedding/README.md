# MA-391 — Quotient-remainder compositional embedding Mirror address

Status: protocol frozen before development. Dedicated branch: `research/ma-391-quotient-remainder-mirror-embedding-20261009`.

## Mirror insertion

**Mirror insertion:** add one token-specific Givens angle over the two fixed component rows selected by exact quotient/remainder addresses. The candidate changes the composition coordinate; it does not change the address, source tables or decoder.

## H — Hypothesis

On a deliberately aligned collision-free quotient/remainder embedding fixture, one angle per token can retain vector/task quality and reduce actual complete payload bytes relative to independent embeddings and direct two-coefficient composition, while improving over fixed addition, elementwise product and concatenation-projection.

## T — Frozen design

PA59 supplies the quotient/remainder complementary-partition prior art. Vocabulary size is 1,024 with unique 32×32 quotient/remainder pairs, 16-dimensional component tables, and two fixed development worlds. Compare independent embeddings, fixed addition, elementwise product, concatenation with a paid fixed projection, unconstrained direct coefficients, and Mirror angles. All serialized tables, codes, decoder, projection state and metadata are charged. See `PROTOCOL.json` for gates and sealed fresh seeds.

The teacher is intentionally generated by the Mirror orbit. This is a representation-feasibility screen, not a natural-data result. The shared source tables stay fixed to isolate composition/code effects.

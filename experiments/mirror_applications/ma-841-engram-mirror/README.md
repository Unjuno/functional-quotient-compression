# MA-841 — AI Engram traces with Mirror basis compression

## H — hypothesis

A shared rank-4 basis plus per-memory coefficients may preserve Engram causal behavior at lower actual bytes than storing every exact trace. A same-rank PCA control tests whether this is ordinary subspace compression.

## T — planned test

Synthetic 8-dimensional key/value memories with exact ridge/closed-form traces. Eight development traces estimate the basis. Fresh worlds contain aligned low-rank memories and residual/private boundary memories. Evaluate sufficiency, reactivation, specificity, necessity and actual payload bytes. PA227 motivates these causal diagnostics.

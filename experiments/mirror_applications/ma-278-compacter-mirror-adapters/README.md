# MA-278 — Compacter Mirror hypercomplex adapters

## H — Hypothesis

Shared Compacter slow weights and fast-factor atoms, addressed by small task codes, may recover multiple adapter functions with less serialized state than native per-task factors. Independent updates test when private fast factors are needed.

## T — Planned experiment

Frozen 16×16 map, eight synthetic tasks, shared atoms and independent low-rank updates. Initial development showed the serializer double-counted W and aligned targets varied four coefficients while Mirror used one. Before fresh, aligned tasks were fixed to a scalar over one shared atom direction and serialization now charges W/bases/codes once. Earlier development rows remain exploratory. Compare no adapter, native Compacter, Mirror scalar, generic coefficients and independent rank-2 LoRA. Fresh worlds 27810–27812 × seeds 0–2 remain locked.

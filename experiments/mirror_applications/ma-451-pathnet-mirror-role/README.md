# MA-451 — PathNet path plus Mirror module role

## H — Hypothesis

A compact role coordinate lets a selected shared physical module provide distinct useful behaviors on held-out task pathways, improving on PathNet path selection alone at lower storage than independent modules.

## T — Planned test

Synthetic two-layer modular regression with four physical modules per layer. Compare PathNet path-only, path plus layer-specific Givens role, independent per-task modules, and shared-only. Fresh held-out paths use disjoint task IDs and worlds; actual serialized bytes and active compute are measured.

## D — Pending

Protocol frozen; implementation and results pending.

## C — Strongest counter-hypothesis

Path selection already identifies the useful module composition; Mirror roles may add parameters and transforms without improving held-out task quality.

## U — Unknown

Whether Mirror role coordinates add useful multiplicity beyond PathNet's path identity under matched physical storage.

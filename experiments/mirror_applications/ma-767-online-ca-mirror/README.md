# MA-767 — Online CA task adaptation in Mirror-code space

## H — hypothesis

Online updates to a compact rule-view code may adapt one shared cellular-automaton transition rule to many tasks while retaining earlier tasks at lower bytes than private rule snapshots. Independent rules test the private-state boundary.

## T — planned test

A local-rule prediction screen for 1D binary cellular automata. Four development rules estimate a rank-2 basis; each fresh world has four in-subspace rules and four independent rules. Compare frozen shared rule, online Mirror code, full-rule online adaptation and per-task independent rule snapshots. Audit seeds and gates are locked in `PROTOCOL.json`. PA198 motivates online adaptation and retention.

SCREENING.

## C — strongest counter-hypothesis

The task rules may already be representable by a small shared basis, so observed compression could be ordinary low-rank parameterization; independent rules may require private weights.

## U — unconfirmed

No results yet. This is a local transition prediction screen, not an autonomous CA pattern-generation benchmark.

## Fact / Interpretation / Hypothesis

- Fact: PA198 treats online task changes as part of self-organising neural cellular systems.
- Interpretation: per-task retention and actual state bytes are required to distinguish compact adaptation from overwriting.
- Hypothesis: a compact code bank can preserve useful logical transition rules while full local-rule state marks the hard-task boundary.

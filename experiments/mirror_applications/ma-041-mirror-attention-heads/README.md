# MA-041 — one QKV to multiple Mirror heads

Status: **PROMISING** for aligned aggregate attention output/storage; head utility and runtime remain limiting.
Evidence lane: MECHANISM / STORAGE / RUNTIME.
Branch: `research/ma-041-mirror-attention-heads-20261007`.
Base commit: full SHA in `PROTOCOL.json`.

## H — Hypothesis

A single physical QKV projection plus per-head input-space Givens coordinates can recover attention output from four logical heads at lower actual payload than ordinary MHA. Hard tying and simple learned head controls define the lower frontier; independent QKV defines a private-parameter boundary.

## T — Test

A synthetic 16D full-attention block, sequence length 8, four 4D heads and shared output projection. Compared ordinary independent-QKV MHA, hard-tied QKV, per-head QKV gains, rank-1 QKV residuals, and shared-QKV Mirror views. Teacher modes used shared QKV plus four fixed Givens views or four independent QKV projections. LR 0.003 was selected on development world 41000; fresh worlds were 41001–41003; each model trained 900 updates.

## D — Decision: PROMISING (scoped)

### Fact

- Aligned attention-output MSE: Mirror 6.90e-5 / 9.97e-5 / 1.06e-4; full MHA 3.67e-4 / 4.27e-4 / 3.27e-4. The <=1.10x output-MSE gate passed 3/3.
- Actual serialized payload: 4,065B vs 6,053B MHA (32.8% fewer); byte gate passed 3/3. Mirror also beat hard tying (1.16e-3–2.03e-3) and rank-1 residual (4.84e-4–7.48e-4) on aggregate output MSE.
- Head contribution audit tells a different story: Mirror worst-head error was 0.0115–0.0159 vs full MHA 0.0084–0.0115. The aggregate output is better, but matching each head's contribution is not established; cross-head compensation may explain the gap.
- With independent QKV teachers, Mirror MSE was 0.0112–0.0124 vs full MHA 6.4e-6–1.14e-3. Shared views do not recover arbitrary QKV functions.
- Mirror active-compute proxy was 165.9M vs 191.7M full MHA (-13.5%). Median training time was 8.08s vs 2.90s, and CPU inference throughput 44k vs 83k examples/s (0.53x).
- 30 fresh rows replayed with exact payload bytes; max output-MSE delta 4.93e-12, worst-head delta 4.86e-12, R² delta 4.9e-9. Tests: 3 passed.

### Interpretation

A shared QKV object plus per-head views improved aggregate attention output and storage for this deliberately aligned teacher and outperformed tying and rank-1 residual controls. This is a fixed-budget mechanism signal, not increased independent capacity. Head-level functional usefulness remains unconfirmed because individual projected contributions differ, and current eager rotations reduce measured runtime despite a lower MAC proxy.

### Strongest counter-hypothesis

The aligned teacher was generated by the Mirror family, so shared coordinates have an exact inductive-bias match. MHA may need more updates to close the aggregate gap, and the head-contribution audit suggests the student uses compensating head outputs rather than recovering the teacher's individual heads.

### U — Unconfirmed

Head ablation utility, attention-map similarity, language-model NLL, optimized kernels, larger/causal attention, and near-convergence fixed-byte quality remain untested.

## Fact / interpretation / hypothesis

- **Fact:** aggregate output/storage gates passed 3/3; independent QKV failed; head contributions and CPU runtime lagged.
- **Interpretation:** this is a useful aligned attention-output view, not evidence that each logical head retains independent utility.
- **Hypothesis:** explicit head-utility regularization or fused view kernels may improve the frontier; untested.

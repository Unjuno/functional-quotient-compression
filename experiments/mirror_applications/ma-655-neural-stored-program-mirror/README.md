# MA-655 — Neural Stored-program Memory with Mirror programs

Status: SCREENING. Test whether a small function coordinate can compose shared linear programs into useful stored and unseen functions.

Program memory stores four basis controllers and per-program codes. Compare an independent full matrix bank, an explicit Neural Stored-program Memory basis/code implementation, a learned Mirror/PCA function basis, its native PCA control, and one-hot nearest-program retrieval. Evaluate held-out inputs for both stored programs and unseen coefficient codes; actual payload bytes include every basis, code, key and decoder object.

This is a synthetic linear program-memory screen, not a paper reproduction. See `PROTOCOL.json`.

# Execution blocker

Only one-scene HNeRV Bunny frames are available; there is no verified multi-scene scene-cut dataset. The native NerVast/adaptive private INR comparator and its fitted weights are also unavailable, and there is no CUDA device for decoder speed. Relabeling temporal windows as cuts or fabricating a cut would not satisfy the registered task.

Disposition: **UNTESTED**, not FAIL.

# MA-424 — mode-conditioned Neural ODE vector-field views

## H — falsifiable hypothesis

Four mode-specific rotated dynamics can be represented by one learned linear vector field plus one angle per mode, approaching independent vector fields at substantially lower actual bytes without increasing solver NFE or stiffness.

## T — protocol

Synthetic 2D stable linear ODEs, with each mode generated by rotating a shared base matrix. Compare shared, angle-conditioned Mirror, scalar mode gate, rank-one matrix residual, and independent matrices. Fit vector fields from derivative samples, then integrate held-out initial states with RK4 at fixed steps. Report endpoint trajectory error, solver NFE, eigenvalue stiffness ratio, bytes, and wall clock.

This is aligned linear-dynamics evidence, not a nonlinear Neural ODE benchmark.

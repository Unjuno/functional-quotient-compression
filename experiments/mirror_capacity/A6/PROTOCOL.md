# A6 — Multi-function capacity on real handwritten digits (protocol frozen before training)

Date: 2026-11-15. Lane: real tabularized image samples, *not* pretrained LLM evidence, not a natural-language claim. New experiment after A5: discovery/exploratory, not an independent preregistered confirmatory trial.

## Question
Can a small, task-indexed two-sided shear Mirror achieve better *held-out multi-function binary prediction* at equal stored FP32 bytes than input-adapter, FiLM, output basis, low-rank and standard multi-head controls, when targets do not come from a Mirror teacher?

## H / T / D / C / U
- H: Mirror4 beats all named non-Mirror families in >=5/6 dataset/mapping worlds at each cap on IID BCE and has OOD BCE no worse than the selected control in >=5/6. Practical storage PASS requires for >=5/6 worlds the smallest tested Mirror actual serialized-byte footprint meeting IID balanced accuracy >=0.80 **and** OOD balanced accuracy >=0.70 be <=0.9 times the smallest passing non-Mirror control. No extrapolation between tested caps; if no model passes, label censored.
- T: `sklearn.datasets.load_digits` bundled 1,797 8x8 images with 64 input features normalized by 16. Worlds 600..605. Two function families: `mask` 16 random distinct 5-of-10 positive digit class subsets per world; `xorink` same masks XOR the **single** training-split-calibrated feature `(normalized image ink sum > train median)`; labels for test computed from unperturbed pixels. Task masks vary by world but are never passed to student. Dataset stratified train/val/test = 60/20/20; each raw image ID belongs to just one split. OOD test = held-out test images plus independent clipped Gaussian pixel noise sigma 0.15, labels unchanged. Seeds 0,1. Whole model serialized FP32 byte caps 6,000 and 12,000 including 32-byte header and 32-byte digest. Seven students: `mirror4`, `pre4`, `film4`, `basis4`, `lowrank4`, `dense4`, `multihead`. `mirror4` has Q^{-1} GELU(Qv) with 2x2 shear blocks; `pre4` removes inverse. `multihead` is a single shared FFN with 16 learned independent scalar heads. 6 worlds x 2 families x 2 seeds x 2 caps x 7 models = 336 checkpoints. Fixed 700 AdamW updates, batch 256, lr 0.005, weight decay 0, max gradient norm 5, one CPU torch thread per worker; full train targets from digit labels, no separate teacher distillation. Only final-step checkpoints selected. No audit evaluation before training is completely finished and hashes locked.
- D: Validation BCE chooses one best non-Mirror model per world/family/cap from **mean across seeds** (fixed rule). Report IID test BCE ratio Mirror4/control, OOD BCE ratio, stratified bootstrap/t intervals over 6 independent world mappings (df=5), plus macro balanced accuracy for each family/cap. Count wins with strict inequality. Count quality passing caps per world. Negative outcomes must be recorded. Six mappings of the same underlying real dataset are NOT six independent image datasets; confidence intervals on maps alone do NOT generalize to new source domains.
- C: Simpler shared output head/basis or affine modulation may dominate; tight budget may make all models fail; rare function masks or XOR complexity may conflate optimization and representation. Even a Mirror win could be overfitting to task construction/architectural prior, not information creation.
- U: finite 1,797-image dataset, overlapping raw source across mapping worlds, random mapping selection, fixed two seeds, 700 steps not converged, OOD noise selection, quality thresholds, numerical nondeterminism, model code/kernel description uncounted, unmatched active compute. For world mean log ratio use standard uncertainty s/sqrt(6), Student-t k determined from df5; use Bonferroni per-family/cap four tests as exploratory interval. Also report raw per-world performance.

## Data and measurements
- Image preprocessing is fixed (divide by 16); no outside data download. Mask sampling uses a deterministic RNG independent from network training RNG. `xorink` threshold computed on **train image** only, no test or label leakage into training.
- Task IDs 0..15 are seen in train/val/test; no unseen-task extrapolation claims. Each task has the same image indices within each split. A world is the image split and task map pair. Check uniqueness of task masks, sample IDs, and positive-label fractions.
- Exact bytes = 32 B header + 4 B per serialized float32 learned scalar + 32 B SHA256; does not charge common decoder source, Python, CUDA (none), optimizer, activations, or task definitions, thus not deployment MDL.
- BCE uses logit binary-cross-entropy (nats per task-image), not log-loss of 10-way digit classification. Balanced accuracy is average over 16 tasks of half(TPR+TNR), if both classes present. OOD uses original uncorrupted target labels.
- Controlled for total *optimizer updates and batch size*, not FLOPs/latency. Record hardware identifier and measured elapsed times with non-fixed clock.
- Before audit, persist manifest of every model including SHA-256 digest, byte length, protocol SHA256 and dataset fingerprint; abort on any mismatch.

## First-principles caution
- Any one fixed invertible Mirror transform can be folded into adjacent learned matrices, so a single fixed view cannot increase the hypothesis class of an unconstrained FFN. The question is conditional sharing across multiple indexed Q operators.
- The `multihead` model is a strong conditional output baseline; no task labels or masks are encoded for free in model weights.
- Related work: FiLM DOI 10.1609/aaai.v32i1.11671; BatchEnsemble arXiv:2002.06715; scikit-learn digits dataset documentation.

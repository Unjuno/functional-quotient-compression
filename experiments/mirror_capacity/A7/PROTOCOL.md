# A7 — Conditional nonlinearity under image-derived compositional tasks

Protocol frozen before A7 confirmatory-world training, 2026-11-15.
This is an exploratory new task family following negative A6; do **not** interpret it as preregistration independent of the A1–A6 research trajectory.

## Question and competing explanations
A6 multihead dominated task-specific digit masks, a task naturally solved by shared features and separate linear heads. A7 asks whether task-conditioned nonlinear hidden representations are useful when 16 binary decisions depend on **different conjunctions or parities of two image-derived features**, without a Mirror teacher. No teacher network, Mirror matrix, or learned target generator is involved. Any positive Mirror effect must beat conditional FiLM, output-basis, low-rank, code-concatenation and multihead controls.

## Pre-run H / T / D / C / U
- H: Mirror4 beats the validation-selected non-Mirror control in at least 5/6 A7 worlds on IID BCE **and** 5/6 worlds on noise-OOD BCE at **both** FP32 caps, on at least one of two fixed function families (`pair_and`, `pair_xor`). Primary stored-rate PASS further requires both IID balanced accuracy >=0.80 and OOD balanced accuracy >=0.70 with at least 10% fewer bytes than the best passing non-Mirror model in >=5/6 worlds. Failure to show a passing point is *censored*, not proof of no possible compressed representation.
- T: `sklearn.datasets.load_digits` 1,797 images, 8 spatial contrast templates defined in code, thresholds equal train-only medians. Fixed 16 image-derived task pairs per world selected from 28 unique pairs using only train feature prevalence; no task pair, threshold or template is provided to students. Task labels: AND or XOR of the two train-calibrated binary predicates, applied identically to held-out original pixels. Train/dev/audit split is image-ID disjoint and digit-stratified, 60/20/20 per world. OOD uses test images with clipped additive N(0, 0.08²) pixel perturbations, *original* target labels. Six new dataset/map worlds 700..705 (development-only world 699 is not used for inference); seeds 0,1; budgets 6000 and 12000 bytes; 7 architectures from A6 (`mirror4`, `pre4`, `film4`, `basis4`, `lowrank4`, `dense4`, `multihead`); 1200 AdamW updates, lr 0.005, batch 256, gradient clip 5, weight decay 0, FP32 CPU. Total 6×2×2×2×7=336 checkpoints, no early stopping, code/protocol hashes locked before train. Development-only world 699 may be used for smoke checks but not for selecting these A7 settings.
- D: After ALL training files are locked, recompute validation, IID, OOD with round-tripped saved weights. Within each world/family/cap select strongest non-Mirror kind by **seed-averaged validation BCE**, then report mean-of-seeds world BCE ratios, 6-world geometric mean and 4-comparison Bonferroni-adjusted 98.75% t intervals. Report component model means and full quality frontier. Avoid best-IID cherry-picking; compare both mirror4 and pre4 to the same selected control. Primary verdict uses mirror4.
- C: A nonlinear task-dependent output head or FiLM may dominate; task width / code dimension / optimization budget differ; positive signal can stem from inductive bias, not a Shannon or MDL gain. Shared feature basis can learn all 16 functions as width increases.
- U: All worlds use **one underlying digits dataset**; 6 worlds are not independent source datasets. Two seeds, finite examples, 1200 steps without convergence proof, threshold-based targets sensitive to noise, no matched FLOPs, runtime/framework bytes not charged, held-out tasks NOT evaluated. Treat intervals as exploratory world-mapping variability, not inference to new domains.

## Feature and task construction
Eight **fixed, non-learned** 8×8 signed contrast templates (horizontal, vertical, diagonal, anisotropic/radial and periodic contrasts) each zero-mean/unit-length. Each binary predicate is whether the corresponding template projection exceeds the **training split median**. Sixteen pairs selected without replacement per task family and world, preferring train-label prevalence from [0.18,0.40] for AND and [0.30,0.70] for XOR; if too few admissible pairs, the run must fail before training. Stochastic pair order is seeded by world and family. Students receive raw normalized 64 image pixels and task index 0..15, never template values or pair definitions. Task construction may favor compositional models, **not Mirror specifically**.

## Exact scope of costs
Whole FP32 learned-weight file = 32-byte architecture header + 4 bytes per scalar + 32-byte SHA-256 digest. Decoder/program bytes, hard-coded teacher task-definition bytes, optimizer states, activations, and data are excluded. Caps are weight-file caps, not deployment description length. Training measures wall-clock on CPU but controls only update count and batch, **not FLOPs**. Model widths are maximized separately within each cap; architectural class and widths must be reported.

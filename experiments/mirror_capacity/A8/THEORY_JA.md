# A8: 線形タスクヘッドの階数制約と条件付き非線形変換の構成的比較

**主張の範囲**: 出力ヘッドが「タスク共通の隠れ表現に対するアフィン写像」である場合の有限標本上の厳密な表現限界。Mirror全般の情報量・汎化性能・学習容易性の優位性は導かない。

## 2. 命題1: タスク共通表現＋アフィンヘッドの階数上限（完全な証明）

タスクに依存しない任意の表現 `f: R -> R^h` を入力点に適用して `H` を構成し、タスク別アフィン読み出しを `Yhat=HW+1_n b^T` とする。

1. `C1_n=0` である。なぜなら `C1_n=(I-1_n1_n^T/n)1_n=1_n-1_n n/n=0`。
2. よって `CYhat = CHW + C1_n b^T = CHW`。
3. 行列積の階数は各因子の階数を超えないので `rank(CYhat)<=rank(H)<=h`。この結論は `f` の非線形性や学習済み・未学習に依存しない。
4. 特異値分解による低階数近似定理から、`CY` と任意の階数h以下の行列との差のFrobeniusノルムの二乗は、`Σ_{j>h} σ_j²` 以上である。
5. `C` は直交射影であり演算子ノルムが1なので、`||Y-Yhat||_F² >= ||C(Y-Yhat)||_F² >= Σ_{j>h}σ_j²`。
6. 従って、全 `nK` 要素で平均した二乗誤差の下界は `Σ_{j>h}σ_j²/(nK)` である。

これは特定の学習アルゴリズムの失敗ではなく、幅hの共通特徴＋タスク別アフィンヘッドという関数族の限界である。

## 3. 命題2: A8の教師行列の中心化階数は16（完全な証明）

タスクを閾値が小さい順に並べ、`x_0=t_1-2ε`、`x_i=t_i+ε` (`i=1,...,K`) を選ぶ。`ε` は隣接閾値差の最小値と各ランプ幅の最小値の両方より小さい正の値とする。A8実装は `ε=0.75 min(t_{k+1}-t_k)` を使い、実験条件では全ランプ幅より小さい。

- `x_0<t_1` より教師の第0行はどちらの関数族でも0。
- `j>i` なら `x_i=t_i+ε<t_{i+1}<=t_j` なので、両関数族の教師出力 `Y_{ij}=0`。
- `i=j` なら `Y_{ii}=ε>0`。ランプ型の場合は右閾値に達していないので第2ReLU項は0。
- よって第1〜第K行と全K列からなる正方部分行列は、対角がすべてεの下三角行列であり行列式は `ε^K !=0`。従って `rank(Y)=K`。
- もし `CYz=0` なら `Yz=c1_n`。第0行が0なので `c=0`、従って `Yz=0`。Yの列は独立だから `z=0`。よって `rank(CY)=K=16`。

したがって `h<16` の任意の共有特徴＋線形タスクヘッドは、この17点の教師出力を厳密に再現できない。

## 4. 命題3: Mirrorは同じ関数を少幅で表現可能だが、Mirror固有の利点ではない

入力を `v=(x,-1)^T` とし、せん断コード `a_k=t_k` とする。`Q(a_k)v=(x-t_k,-1)^T`、要素ごとにReLUを適用すると `(max(0,x-t_k),0)^T` になる。`Q(a_k)^{-1}` は第2座標が0なので第1座標を変えず、共有下流重み `(1,0)` で教師のhingeを正確に出力する。

rampでは同じ幅2の組を2組使い、コードをそれぞれ `t_k,u_k`、共有下流重みを `(1,0,-1,0)` とすれば教師出力は差分として正確に出る。幅はhingeで2、rampで4でよい。

**反証を伴う注意**：この具体的構成では、第2ReLU出力が常に0なので逆せん断は実際には何もしていない。逆変換なしの`pre`でも同じ関数を厳密表現できる。入力に直接タスク別の閾値を足すことやFiLMのバイアス変調でも実現できる。Mirror固有の容量倍率は、この構成から導けない。

### 単位・次元チェック

入力・閾値・ReLU出力はすべて無次元（SI単位1）。Y、H、Wの積 `HW` は `(n×h)(h×K)=(n×K)` となりYと一致。C Yも`(n×n)(n×K)=(n×K)`。特異値も無次元、二乗和をnKで割ったMSEも無次元。QとQの逆行列はいずれも2×2で、積は無次元の単位行列となる。保存式Bはbyte単位の情報量で、一般SI基底量ではなく8bit/byteという計数単位。

### 保存量の上界の例（プログラムを数えない比較）

16個のFP32閾値を直接保存して既知のhinge公式で復元すれば64Bヘッダー/検証情報と64Bコードで128B。rampは左右32値を保存して192Bで足りる。したがって、少なくとも**この構成済み教師を保存する目的では**、Mirrorネットワークの重みファイルが最短とは主張できない。実行式のコード長は両者とも計上しておらず、汎用関数族への転用を証明する値ではない。

## 5. 研究上の含意

(i) 行列階数の制約を超えることは重要だが、Mirrorの独自性ではない。(ii) 他の低記述長の条件付きシフト、FiLM、入力アダプタ、共有基底モデルとの比較が必須。(iii) 実測学習に失敗しても、その原因は表現能力不足と最適化失敗を分離すべきである。

# A5 — native representation capacity, pre-run protocol (2026-11-15)

## Research question and rationale
Can a task-indexed invertible shear around GELU (Mirror) beat straightforward conditional representations in *stored bytes at held-out functional quality* when the teacher does not contain a Mirror mechanism? A4 and A4b found no Mirror-specific advantage against FiLM or output-basis adapters. This experiment studies two externally generated function families, with **no Mirror teacher**.

## H / T / D / C / U
- **H**: At the same serialized weight-file cap, Mirror4 yields smaller held-out IID normalized RMSE than the best non-Mirror control, while maintaining no worse OOD error. A useful rate-quality win further requires an actual 10% lower *minimum tested cap* at IID NRMSE <=0.40. These are separate claims.
- **T**: Worlds **500–505**, seeds **0 and 1**, tasks **16**, teacher families **compositional** (sum of 4 randomly initialized independent MLPs with task-dependent coefficients), **independent** (16 independently generated MLP functions). Student kinds **mirror4**, **pre4** (inverse removed), **film4** (affine), **basis4** (output basis), **lowrank4** (rank4 conditional up-weight), **dense4** (task embedding appended to input). Caps **1500, 3000** whole-file bytes. 6 worlds × 2 seeds × 2 families × 2 caps × 6 kinds = **288 models**. 800 AdamW training updates, lr=0.008, batch=256, weight_decay=0, clipping 5, CPU FP32, 1 thread/worker, exact GELU, no best-checkpoint selection. Train sizes 384 inputs per task, separate val128, IID256, OOD256, all 16 tasks share X per split. OOD scale 1.6. All task IDs are seen in training.
- **D**: Select no checkpoints or configurations on test. Compare world means of two seeds. Mirror gets a *discovery signal* for a family/cap only if it wins against each named non-Mirror model in >=5/6 worlds on IID test and its OOD NRMSE is no worse than the best control in >=5/6. A **practical-rate PASS** requires that >=5/6 worlds have Mirror's minimum tested passing cap <=0.9 times the minimum tested passing cap among controls. If threshold is unreached by any model, report censored and do not call PASS. Otherwise report FAIL for the tested config. Exploratory 95% t intervals on world mean log ratios, not evidence of population normality.
- **C**: A student may succeed through ordinary shared features and conditional output adapters; if Mirror does not beat these, there is no Mirror-specific capacity evidence. Independent tasks may be too diverse for any tested model and prevent identification.
- **U**: Small number of worlds, two seeds, fixed 800-update optimization, structural difference in hidden widths, finite input testing, teacher bias, data generation and hardware. Use `u_c = s_world/sqrt(6)` for the mean log ratio and nominal Student t interval with k=2.571 (df=5). Exploratory gate is not a preregistered journal-level multiplicity adjustment.

## Evidence split and provenance
- `train.py` produces exact FP32 serialized weights, frozen protocol and manifest, and **does not evaluate IID/OOD data**. `audit.py` verifies a locked manifest before loading 288 models and computes IID/OOD; no model selection uses these sets. Checksum failure is fatal.
- Bytes: 32-byte header + all learned FP32 scalars (including task-specific code vectors and all learned adapter bases) + 32-byte SHA256 trailer. Common decoding Python source, runtime, teacher generator, activation buffers, optimizer state, KV cache (none), and activation tensors are excluded. This is *weight-file accounting*, not total deployment-system MDL.
- Costs: active FLOP/MAC accounting is not equalized between architectures. 800 updates match update count and batch, **not** compute. Record actual wall-clock time per model and CPU provenance; no GPU claims.
- Tests must verify serialization round-trip, flipped checksum rejection, budget compliance, code dependence, shear inverse identity/explicit-weight equivalence, deterministic teacher and train/test independence.
- Follow-ups chosen after seeing A5 must be marked **exploratory**, not independent confirmatory testing.

# E002 — Cross-block coupling

Status: **mechanism recovered; original numerical instance not yet recovered**.

The archived result shows that a diagonal/additive distortion model can
underestimate the true quadratic task distortion and can therefore create a
false hard-budget PASS. It also records a safe block-row-sum majorizer based on
cross-block operator norms.

The canonical implementation currently includes the scalar-block special case,
which makes the safety inequality explicit and testable without introducing a
large numerical-linear-algebra dependency. The original 38-state codec universe
and the reported threshold-specific bit counts remain provenance claims until
their generator is recovered or independently reconstructed.

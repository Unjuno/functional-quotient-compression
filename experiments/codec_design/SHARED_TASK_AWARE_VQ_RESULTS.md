# Shared task-aware VQ: synthetic architecture results

This note records the high-value results from container-side synthetic experiments T100–T114. These are **synthetic codec-design results**, not real Transformer compression evidence.

## 1. Metric consistency is essential

For heterogeneous diagonal tensor families, naive normalization followed by ordinary Euclidean shared VQ can be substantially worse than local codebooks. In T100/T101, metric-consistent normalization — i.e. transforming the distortion together with the representation — recovered most of that loss.

Representative result:

- local codebooks: NMSE ≈ `0.689`
- raw shared codebook: `0.767`
- normalized + Euclidean shared: `0.834`
- normalized + original-space weighted shared: `0.717`

Across a heterogeneity sweep, metric-consistent shared VQ stayed within roughly `0–5%` of local-codebook NMSE even when naive normalization degraded by up to about `39%`.

With `D=32`, `K=256`, and a 4-bit shared codebook, metric-consistent shared VQ was only about `0.98%` worse than per-tensor local K=256 codebooks. A 3-bit codebook was about `1.47%` worse.

Per-tensor 32-dimensional normalization scales could be quantized to 4-bit log-scales with about `0.04%` NMSE change in the tested setup.

## 2. Paid low-description alignment can make sharing viable

In T104, each tensor orientation was generated by eight Householder reflections. A paid six-bit representation of those eight reflections, followed by shared VQ, improved NMSE by about `6.5%` relative to local codebooks while using much less representation metadata.

A complexity control in T105 is important: when the true orientation used 31 Householder reflections, paying for only 8/16/24 reflections did not recover local quality. Paying for all 31 did. Thus the transform must have enough description capacity to represent the actual geometry; an arbitrary low-description transform is not automatically useful.

## 3. Alignment, normalization, metric transformation, and sharing are complementary

T108 combined orientation heterogeneity and variance heterogeneity. The full primitive used:

- 8 paid Householder reflections per tensor, quantized to 6 bits;
- 4-bit per-dimension log scales;
- a shared 4-bit codebook;
- metric-consistent weighted assignment.

Results:

- local codebooks: NMSE `0.6806`
- raw shared: `0.7372` (`+8.3%` vs local)
- transformed but unweighted Euclidean shared: `0.7775` (`+14.2%`)
- **full metric-consistent shared primitive: `0.6684` (`-1.8%` vs local)**

Synthetic metadata in this experiment was `6,704` bytes for the shared primitive versus `49,152` bytes for local codebooks.

The interpretation is not that an invertible transform creates information compression. The transform is paid; the benefit arises because a restricted shared codec works better in an aligned coordinate system with a consistent distortion metric.

## 4. Task-aware VQ separates functional distortion from reconstruction distortion

T109 directly optimized a synthetic task-weighted distortion rather than Euclidean reconstruction error.

- Euclidean shared VQ task NMSE: `0.7499`
- task-aware shared VQ task NMSE: `0.6194`
- improvement: **17.4%**

At the same time, ordinary reconstruction NMSE worsened by about `14.9%`. This is deliberate: the codec reallocates error toward task-cheap directions.

Most of the gain came from task-weighted assignment; retraining the shared codebook under the task metric added further improvement.

A task-anisotropy sweep (T110) gave task-aware improvement of approximately:

- isotropic task metric: `0%`
- mild anisotropy: `1.15%`
- moderate: `5.04%`
- strong: `19.33%`
- very strong: `36.65%`

## 5. Full task-aware shared primitive

T111 combined paid alignment, quantized scales, a shared 4-bit codebook, and task-aware distortion.

- shared Euclidean task NMSE: `0.7618`
- **shared task-aware: `0.6195`**
- local task-aware: `0.5996`

Thus the shared task-aware codec was only about `3.3%` above local task-aware quality while using about `20.5%` of the local metadata in the constructed setup.

T112 swept index rates:

| index rate | shared Euclidean | shared task-aware | local task-aware |
|---:|---:|---:|---:|
| 0.125 bps | 0.812 | 0.716 | 0.670 |
| 0.1875 bps | 0.743 | 0.630 | 0.610 |
| 0.25 bps | 0.692 | **0.566** | 0.590 |

At 0.25 bps, shared task-aware slightly outperformed local task-aware in this sample-limited synthetic setting, consistent with a training-data pooling effect.

## Boundaries

Do not infer that:

- these NMSE values predict SmolLM2 quality;
- the synthetic task metric equals a Transformer task metric;
- the Householder family used here exists in real model tensors;
- shared VQ is always preferable to local VQ;
- these results establish 64× feasibility.

The main architectural conclusion is narrower: **low-description alignment, shared representation, and task-consistent distortion must be optimized together; applying only one of these pieces can fail.**

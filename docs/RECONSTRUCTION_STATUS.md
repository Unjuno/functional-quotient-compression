## Current invariant suite

The canonical test suite currently checks:

- raw logical bits cannot override serialized hard-budget accounting;
- serialized and logical Pareto frontiers can differ;
- cross-block terms can make a diagonal objective optimistic;
- row-sum coupling majorization is safe in the implemented scalar-block case;
- decoded-state quotienting preserves prerequisite distinctions;
- invalid quotient classes with unequal distortion are rejected;
- surrogates rank candidates but cannot commit unvalidated changes;
- description-only rotation transfer preserves the optimum distortion value;
- exact conditional Pareto pruning preserves budget optima;
- joint layout/precision moves can strictly dominate both coordinate-only moves.

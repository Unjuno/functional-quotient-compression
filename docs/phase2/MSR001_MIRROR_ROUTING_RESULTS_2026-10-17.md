# MSR001 — Mirrorコード連動ゲート／自己ルーティング研究（2026-10-17）

**判定：Mirrorで専門家の機能差を作る方法は候補として残すが、同じMirrorコードをそのままルータにも共有する方式は、今回の事前固定条件では FAIL。** 既存のMA-006/007やMLPの成功例を否定するものではない。main・正式MA判定には変更を加えない。

## 検証した科学的な区別

- **機能Mirror：** 1つの共有SwiGLUのgate/up/downから、4つの論理専門家をGivensコードで変形して生成する。
- **独立ルータ：** 通常の小さな線形層で各入力に専門家を選択する。
- **Mirror連動ルータ：** 専門家のgate変形コードと固定プロトタイプからルーティングスコアを生成する。同じ学習コードが「専門家の機能」と「その専門家が選ばれる領域」の両方を制御する。
- **強い対照：** 同数コードのnative gain連動ルータ、別学習プロトタイプ、普通のゲート、4つの独立専門家。

完全に連動させるとパラメータ節約にはなるが、ルーティングと関数近似の異なる勾配目的が同じ座標へ競合する可能性がある。交差勾配を測定しただけで「勾配衝突が主因」とは確定していない。

## H / T — 事前固定した実験

CPU / PyTorch 2.10.0+cpu / FP32 / AMD EPYC 9V74 / 単一スレッド×3ワーカー。各専門家は8→16→8のSwiGLUで、論理専門家4、Givensはgate/upそれぞれ8角／専門家。

- **開発：63モデル。** 世界99200、3学習率×3教師系列×7方式、400更新。開発検証NMSEにより全方式共通LR0.015を選択。
- **主評価：210モデル。** 新規5世界99311–99315×2初期値×3教師系列×7方式、各1,000更新、batch64、役割ラベルへの交差エントロピー係数0.15を全方式に適用。
- **後から別途固定した追補：96モデル。** 新規3世界99421–99423×2初期値×2教師系列×4方式×{役割教師CE=0.15, CE=0}、4,000更新、同じモデルの1,000/4,000更新時点の評価を保存。追補は一次の事前判定の書き換えには使わない。
- 世界は独立統計単位、2初期値は世界内対応反復。教師系統は「ルータとMirror機能が同じGivens幾何」「機能はMirrorだがルータが独立」「4機能が完全独立」の3つ。全体で369学習。

損失は訓練側から求めたRMSによる正規化MSE、ルーティング補助CE、評価は別のテスト入力で行う。直線的なTop-1 forwardにstraight-through勾配を使い、**学習も推論のベンチ実装も4専門家すべてを一度評価する**。真の物理的Sparse-MoEの速度を証明する設計ではない。

## D — 一次結果：Givens適合教師の予測性能

数字は「世界内2初期値平均→5世界の中央値」。低い方がよい正規化MSE。

| 方式 | テストNMSE | 学習パラメータ | 実推論byte |
|---|---:|---:|---:|
| 共通MLP | 0.3198 | 421 | 4,689 |
| **Mirror機能＋独立線形ルータ** | **0.1460** | 485 | 5,321 |
| **Mirror機能＋Mirrorコード連動ルータ** | 0.2056 | 449 | 4,689 |
| native gain＋gain連動ルータ | 0.2152 | 449 | 4,689 |
| 独立4専門家＋線形ルータ | **0.0872** | 1,573 | 9,297 |

連動Mirrorは独立Mirrorルータに対し **5/5世界でNMSEが大きい**。世界対応した幾何平均誤差比は**1.405**（記述的世界クラスタbootstrap 95%区間 **[1.235,1.599]**）。平均・最悪役割損失・ルート精度・byteの複合ゲートは **0/5 FAIL**。同数パラメータのgain連動に対し少なくとも5%優れる世界は**2/5だけ**。独立ルータ教師、独立関数教師での一般化ゲートも各**0/5**。

全210モデルで平均専門家利用率5%未満の極端な未使用専門家は0件。教師役割識別率は多くの方法で95%以上あり、単にルータが選べないだけでなく、**選んだ専門家の学習到達度**にも差が残る。

15教師構成に対して正しい教師重みをStudentにコピーすると、各教師を**出力最大差0で再現**できた。したがって当該失敗を「このモデル類では表現不可能」と証明したことにはならない。これは学習なしのoracle再構築であり、実用学習の成功ではない。

## D — 新しい3世界の4,000更新追補

Givens適合教師／役割CE=0.15：

| 方式 | 1,000更新 | 4,000更新 |
|---|---:|---:|
| Mirror連動 | 0.2395 | 0.1759 |
| Mirror＋独立線形ルータ | 0.1994 | **0.1135** |
| native gain連動 | 0.2371 | 0.2140 |
| 独立4専門家 | 0.1109 | **0.0898** |

Mirrror連動は延長により全**3/3世界で15%以上改善**、同数パラメータのnative gain連動より**3/3世界で低いNMSE**。これはMirror変換自体の長時間学習の可能性を示す。ただし独立線形ルータに対する同時品質ゲートは**0/3 FAIL**。Mirrorコードをルータと共有する追加価値は依然として立証されない。

役割CE=0では、同じ教師の4,000更新のNMSEはMirror連動0.3204、Mirror独立ルータ0.2150、native gain連動0.2993。ルータの専門家IDは無教師学習では置換可能なので、生の教師role-ID一致率だけでは判断しない。**ハンガリアン法による最良ID並べ替え診断**でも、Mirror連動の教師役割一致率は約0.536、独立ルータ型は約0.753であり、両者に差が残った（診断ではテスト正解role IDを使っており、実運用用のアルゴリズムではない）。平均利用率5%未満への崩壊は無かった。

## C / U — 制限事項

今回の教師はGivensに合う人工関数で、実画像や自然言語、自然に独立学習したMoEの専門家ではない。役割CEは普通の教師なしMoEより強い学習信号。パラメータ削減と機能品質／同一FLOP高速化は別。CPUバッチ32未融合forwardはMirror連動**0.1688ms**、Mirror＋線形ルータ**0.1303ms**、gain連動**0.1042ms**、独立4専門家**0.0960ms**で、速度優位は無い。クロック固定なし。主5世界・追補3世界だけのため、数値的な母集団外挿は不可。

## 次の使い方

**① Mirror専門家＋普通の安価な線形ルータを基準とする**（今回の共有モデルでは最良）。**② 完全連動でなく、Mirror幾何スコアにrank1/2の小さなルータ補正を加えた部分共有を試す。** 同容量のgain／native低ランクルータを比較し、追加1B・1FLOP当たりの損失改善で判定する。③ ルータCEと専門家MSEの勾配干渉を原因と主張する前に、固定コード・別学習率・段階的温度・入力別負勾配を新世界で因果的に分離する。④ 実際の学習済みFFN/MoEを使い自然データと真のSparse計算で再検証する。

**H/T/D/C/U結果：** H=コード共有でルータ学習が効率化するか。T=上記計369fitと新世界追補。D=一次/長期とも完全連動は独立ルータにFAIL。C=共有コードの最適化制約、教師幾何、nativeゲート。U=合成・少世界・教師ありルータ・小CPU・非融合。

**ERROR CHECK:** Mirror変換の有用性と完全自己ルータの限界を分けた。失敗を表現不可能証明としない。生role精度を置換不変としない。キーワード「Top-1」を物理Sparse速度と混同しない。main/過去MA判定は触らない。

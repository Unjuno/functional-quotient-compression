# DeltaNet writable-state View family diagnostic (2026-11-11)

## Evidence

- MA-851: rank-2 writable state reconstructs the aligned synthetic sequence with 75.4% fewer bytes and lower operation counts than full W, but native low-rank state exactly matches Mirror and is 20 B smaller.
- MA-852: task decay View is exactly a native scalar task gate; same bytes and compute.
- MA-853: key/value role Views exactly equal native factorization; same payload, output and compute.
- MA-855 independently finds the low-rank state code aliases its native low-rank Delta control in a common-task screen.

## Ruling

Pause direct DeltaNet matrix-state coordinate/factorization variants after three consecutive P0 Mirror-specific FAILs with the same structural explanation: ordinary native parameterizations account for the functional freedom. Resume only with a materially distinct write/erase or state mechanism, not a renamed factorization. MA-855 remains a separate scoped benchmark and is NOT ESTABLISHED as a broad frontier because it lacks outer-loop meta-training and task-family coverage.

## Boundaries

All direct-state measurements are synthetic. No trained DeltaNet, language-model, long-context, or accelerator frontier is established.

# Mirror中核方式：活性化×変換×共有自由度の研究項目整理（2026-10-13）

**状態：IDEA INTAKE / 整理のみ。学習・新規実験・選定・PASS判定は実施していない。**

この文書は、Mirrorの応用先をさらに総当たりで増やすものではない。研究対象は、`F(x;theta) -> F(x;theta,m)` の追加低記述量座標 `m` 自体を、**共有方法・変換方式・活性化関数・適用範囲・自由度・専用退避**と共に学習するための設計自由度である。既存MA番号をまず参照し、重複する項目は新たなMA IDを割り当てない。

## 1. 研究する現象

1. 同じ学習パラメータを多数のViewで共有できる一方、軌道に乗らない機能まで共有させると品質が崩壊する。
2. 変換が活性化と可換なら、異なるパラメータ座標でも論理機能は同じになる。単純なView数・重み差・角度差を容量の証拠にしない。
3. 一つのMirror座標は多数の重みを同時変調できるが、それらを独立調整できるわけではない。局所関数自由度 `rank(dF/dm) <= dim(m)` を計測する。
4. 固定された変換族と固定された活性化を**個別にグリッド探索するのではなく**、固定された小さな候補族の選択・係数・適用箇所・有効次元を学習中に共同最適化できるかを検証する。
5. 全MLPに逐次圧縮デコーダを挿入しない。既存の幅広い共有経路を残し、必要な座標・チャネル・ルールのみに低コストのMirrorを適用する。

## 2. 数学的な比較の軸（仮説・実装結果ではない）

活性化が要素ごとに作用する`phi`、可逆View`Q_m`について：

```text
Mirror-after-activation-equivalence: M_phi(Q_m,z) = Q_m^(-1) phi(Q_m z)
Null/symmetry diagnostic:          C_phi(Q_m,z) = M_phi(Q_m,z) - phi(z)
```

`C_phi = 0` ならその作用位置のMirrorは新たな関数を作らない。例えば、ReLUと正の対角伸縮、tanhと要素ごとの符号反転、任意の要素ごと非線形性と要素の単純な置換の組合せを別々に監査する。ReLUは一般の符号反転とは可換ではない。一般の学習可能Q、非線形phiでは差が出ても、その差がタスク有用性になるとは限らない。

軽量な一つの候補族は `Q(m)=exp(K(m)) exp(S(m))`、`K^T=-K`（回転）、`S^T=S`（伸縮・混合）とし、適用強度と非線形活性化の係数を学習する。計算・保存費用が低ければHouseholder/対角/疎マスクも比較する。学習できること、収束保証、既存方式からの独自性は別問題。

## 4. 研究方向の統合軸

- 共有重み`theta`、変換方向`psi`、タスク/状態コード`m`、活性係数`eta`、位置/ランク/部分適用ゲート`g`、private残差`E`を識別して扱う。
- `Q`、`phi`、`g`の基本設計族はあらかじめ**小さく固定**することはできる。一方、どの族がどの対象で使われるか、活性化の形状係数、軸、座標、自由度の使用率を共同学習する。
- 初期の候補は`(no Mirror) | (diagonal) | (rotation) | (stretch) | (private)`の少数に限定し、追加候補は既存対照に負けた理由が明らかになった場合のみ検討する。学習中の軟選択と推論時の疎/硬化の品質差を測る。
- 本文のA〜Dは**提案項目**であり、性能向上/因果証明/新規性/デプロイ準備の確定ではない。「全候補を選ぶための大規模なグリッド実験」は意図しない。
- 初めに追加する価値が高いのは、A1（無効Viewの除外）、A3（小さい活性化基底）、B1/B3/B4（変換/自由度/部分適用の自動調整）、C1（private逃げ道）、D1/D2（偽容量と学習困難の峻別）。これは推奨研究順序であり、結果に基づく優位性ランキングではない。

## 5. 過去研究からの境界

- **MN010**：Mirror数と一状態の変換幅は別資源。狭い状態を数だけ増やすのは弱く、幅を増やすことは一部の世界では有効だが追試は混合。
- **MA-268**：IA3等の活性調整とMirrorは一部の合成実験で効く。ただし活性化族や計算効率の一般優位性は未確立。
- **MA-333/419**：符号/周期構造で変換後の見かけが変わっても、新しい論理機能とは限らない。既存式との厳密同値を最初に調べる。
- **MA-314 / MS012–14**：必要量を動的に割り当てる方針に部分的な信号があるが、より強いnative対照に勝てない領域もある。
- **MA-701-LP01**：学習可能な軸は合成同族課題で良くなったが、実画像で過学習し、最初の開発ゲートは不合格。
- **TCSMA-001/002**：固定リッジ行の近傍対応ペナルティは新規5seedで0勝。共同学習の際、対応損失が**何に直接勾配を流すか**を監査する。

# Loop × LoRA × Vector Mirror — 実測結果

**実施日: 2026-11-05 / Run: LOOP-LORA-MIRROR-20261105**
新しい独立の研究run。MA-1184の結果・判定・中央台帳を変更しない。自然言語モデルの実証でも、既存論文の再現でもない。

## 1. 結論

**120件の共同学習と40件のLoRA置換学習を完了。全160モデルの未使用入力評価を保存モデルから再生し、CE・正答率の最大差は0。** 別に4件の学習率・難易度pilot、2件の完全再訓練を実施。

- 同じ共有Transformerブロックを繰り返す効果は、今回の固定更新予算で明瞭だった。共有のみの未使用同種グラフ正答率中央値は1反復17.97%→8反復92.29%。反復が増えるほど実計算も増え、残差スケールも反復数に合わせて変更している。固定FLOPsの比較ではない。
- Mirrorのみ、Mirror＋LoRAの同種グラフでの点推定改善はある。しかし事前固定したR4のMirror固有品質基準（FiLMとrank1 LoRAの両方へCE10%以上改善、4/5 seed以上）は **0/5 FAIL**。R8の補助比較も0/5。
- 反復別LoRA2が学習した機能を**凍結バックボーン上で**置換すると、rank1 LoRAは中間FFN出力誤差の約93%を回復したが、純Mirrorは約28%。Mirror＋rank1は約95–96%を回復するものの、rank1単独に対する実用上の追加価値は未確立。
- 8反復の全30モデルは、接続構造を単一8-cycleから二つの4-cycleへ変えると正答率0%。同種グラフで高精度でも、一般的な3-hop手順を獲得したとは言えない。

## 2. 実験と公平性

8ノードの有向グラフで、開始ノードから3ステップ先のノードを予測する。TRAIN3000 / DEV700 / Fresh1000のグラフIDは、各seed内で完全に非重複。TRAIN6000問、DEV512問。Fresh/OOD各1024問は**全160選択checkpointの封印後**に初めて生成・評価した。分割のグラフID集合自体は事前に定義している。OODはノード数・語彙を変えず、連結構造だけを変更。これは一つの人工タスク族であり、5seedは独立な訓練・分割の反復であって5つの自然タスク族ではない。

モデルはd_model32、2heads、FFN48のReLU、1個のpre-LayerNorm Transformerブロックを1/2/4/8反復。双方向の集合Attentionで、位置符号・因果マスク・MoEはない。入力は各辺の始点・終点と問合せ。各反復で同じAttentionとMLP重みを共有する。残差更新係数は反復数に応じて固定し、全方式共通。

方式は共有、FiLM、FFN入出力両層のLoRA rank1、同rank2、双反射Mirror、双反射Mirror＋LoRA rank1。Mirrorは二本のHouseholder方向を同じ値で初期化し、開始時に恒等変換を作る。非線形の前に二反射、後に逆順の二反射を適用。旧実験の単一反射と同一構造とは呼ばない。FiLMとLoRAも初期作用は恒等。実入力上の全24初期条件におけるlogit差は最大3.58e-7で、全コード方式に有限の非ゼロ勾配を確認。共有核は同じseedから同一初期値、同じminibatch順で共同学習する。

800 AdamW更新、batch64、lr0.003、weight_decay1e-4、clip1。100更新ごとのDEV CEで選択し、Freshでは一切選ばない。別pilot seed19001でshared/LoRA2 R4の2学習率を比較し、共通lrを決めた。Mirrorの結果に合わせた学習率選択はしていない。各方式に個別最適化した最高性能の比較ではない。

## 4. 学習済みLoRAをMirrorへ置き換えた結果

全R4/R8 LoRA2教師10件を選別せず使用。共有Attention・MLP・正規化・埋め込み・読出しを**完全に凍結**し、4種類の小さいアダプタだけを新たに学習。教師がTRAIN入力上で実行した各反復のFFN入出力を1024問分保存し、それを再現する。DEV256問のFFN出力誤差で選択。600更新、lr0.003、batch64、weight_decay0。正解ラベルは置換学習に使わない。

8反復教師を単にアダプタ削除すると正答率中央値88.09%。Mirror単独への置換は89.55%、rank1への置換は93.07%、元のrank2教師は92.58%。**今回の実用的な小型化候補はMirror単独よりrank1 LoRAだった。** rank1はR4/R8いずれも5/5で教師から2ポイント以内。8反復の実packetは59136→54016bytes（約8.66%削減）。これは教師の学習費用を含む再圧縮で、学習費用そのものの削減ではない。

Mirror＋rank1のコード係数数は元rank2より20%少ないが、今回のtorch.save形式ではテンソル別メタデータ等のため、総packetは逆に59136→59937bytesへ増えた。係数数削減だけで保存量削減と呼ばない。この小規模モデルのシリアライズ形式に依存する結果であり、最小符号長を主張しない。

事前の置換ゲートには「教師がアダプタ削除で5ポイント以上落ちる」という必要性条件も含めていた。これを満たす教師は各Rで1/5しかなく、全条件通過はMirror0/5、rank1とhybrid各1/5。したがってMirror固有の有用な置換を実証したとは言えない。LoRA削除による既存モデルの劣化と、初めからLoRAなしで再訓練したモデルの性能は別問題であり、共有のみのモデルも高精度に到達している。

## 5. 構造OODでの失敗と、ラベルの独立検算

8反復6方式×5seedの**30モデルすべてがOOD正答率0%**。データや評価のバグを疑い、別のPythonループで5,120例の3-hop正解を計算し直したが、ラベル不一致0。正解は必ず開始ノードと同じ4-cycle内にある。

**事後診断（主判定・訓練に使わない）:** R8の共有、LoRA2、Mirror、Mirror＋LoRA1各5seedの計20モデルは、OODの全例で**開始点と別の連結成分**を出力した。無作為に迷うだけの失敗ではない。学習した8-cycleに固有の近道を利用した可能性と整合するが、内部機構を因果的に確定した証拠ではない。

今回の結果を「一般的なグラフ探索アルゴリズムを学習した」「Mirrorに計算手順を詰め込めた」と表現しない。次の独立研究では、訓練中から連結構造・cycle長・要求hopを変え、こうした近道を封じる必要がある。現在のFreshを使って条件を変えて再採点することはしない。

## 7. 診断: LoRAの変更は純粋な回転だけではない

評価前に追加計画を記録した記述的診断として、LoRAの**積から復元した更新行列全体**の特異値を測定した。因子の取り方に依存する値は使っていない。元の共有行列からの相対特異値変化の中央値はR4約8.80%、R8約7.82%。純粋な直交左右変換は特異値を保存するため、重み全体の変化が単なる回転だけではないことを示す。これは**重みの診断**であり、非線形関数近似誤差の下界や性能差の原因の証明ではない。

本実装のMirrorにはbias回転効果もある一方、LoRAは重みのみを更新する。そのため、旧単一反射と結合rank1の包含関係を、この実装の任意のMirror/LoRA組へ無条件に移していない。
